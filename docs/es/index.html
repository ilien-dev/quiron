Quirón, un skill para humanizar textos de IA que mide su propio trabajo

Quirón es un skill para Claude Code, Codex y Cursor. Dale un borrador a tu agente y pídele que lo humanice, o que un README suene menos a ChatGPT. Quita los hábitos que delatan la escritura con IA y después compara la nueva versión con escritura humana publicada antes de ChatGPT, así que recibes el texto nuevo junto con una medición que dice si ya se lee como algo que escribió una persona.

Descárgalo en GitHub Míralo en skills.sh

Instalación

La CLI de skills lo instala en Claude Code y en los demás agentes que soporta, entre ellos Gemini CLI y GitHub Copilot. No hace falta ninguna API key, porque corre sobre el modelo que ya usas, y los scripts no piden nada fuera de la biblioteca estándar de Python 3.

npx skills add ilien-dev/quiron

En Claude Code también puedes añadirlo como plugin desde su propio marketplace:

/plugin marketplace add ilien-dev/quiron
/plugin install quiron@quiron

Qué detecta

Pídele a un modelo un post de blog y te llega con una forma que se aprende a reconocer. La lista de Quirón tiene 33 de estas señales de escritura con IA, y cada una se probó contra posts reales antes de quedarse. Algunas:

  • "No es X: es Y", cuando nadie dijo que fuera X
  • listas de tres
  • el doble de encabezados de los que pondría una persona
  • una sección de "Conclusión" al final
  • palabras que la gente usa todo el tiempo, como muy, hay o porque, que desaparecen

Las expresiones famosas, como cabe destacar o es importante señalar, casi no aparecen ya. En la prueba de este proyecto salieron en 2 de 32 posts de IA en español, y en un 4 a 10% de los humanos. Lo que delata a un modelo en 2026 es bastante más discreto.

Un medidor, no una autoevaluación

La mayoría de los skills para humanizar texto le dan al modelo una lista de patrones y confían en que siga las instrucciones. Quirón también tiene su lista, pero además incluye un script que cuenta 23 tasas en el texto y compara cada una con el rango de 241 posts de dev.to en español escritos antes de 2022. El inglés y la ficción tienen sus propias bandas.

El medidor atrapa algo que una lista no ve. Si le dices a un modelo que escriba como una persona, normalmente se pasa: las frases salen más cortadas y las palabras más simples que las de cualquier persona. El medidor avisa de eso con la misma fuerza que avisa del lado de la IA, así que sabes cuándo parar.

En un tutorial de Stripe escrito por un asistente encuentra 13 de 23 tasas dentro de la banda humana. La nueva versión, hecha a partir de las notas del autor, consigue las 23.

Úsalo con lo que escribes tú

Quirón está pensado para lo que escribes para ti o para tu equipo, como documentación interna o las notas de una reunión. No sirve para hacer pasar texto de IA por humano cuando quien lee tiene derecho a saber quién lo escribió, como en una tarea de clase o una solicitud de empleo. Es gratuito y de código abierto bajo la GNU AGPL v3.

Preguntas

¿Sirve para que un texto pase GPTZero o Turnitin?
No. Esas herramientas leen probabilidades de tokens, y Quirón no las toca. Trabaja únicamente sobre lo que realmente nota alguien al leer.
¿Funciona en otros idiomas?
El español y el inglés tienen bandas medidas y sus propias listas de palabras. Los demás idiomas reciben la lista de patrones como mejor esfuerzo.
¿Se inventa cosas para sonar humano?
Sus instrucciones se lo prohíben. Una nueva versión solo puede usar datos de tu texto o de tus notas, y un script lista los números y enlaces de la versión nueva que no están en el original. Cuando al texto le falta un detalle, el skill te lo pregunta.
