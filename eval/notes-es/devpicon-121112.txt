- contexto: Google I/O anunció los Architecture Components — propuesta del equipo Android para arquitectura recomendada
- componentes: Room, LiveData, Handling Lifecycle, ViewModel; varias dependencias ya estables; este post solo cubre Room
- Room = librería de mapeo objeto-SQL; fin de escribir a mano clases de tablas, sentencias y CRUD (¿"sufrimiento"?, dice con ironía)
- ejemplos en Kotlin a propósito — la red está llena de ejemplos en Java
- update 23 abril 2019: repo y ejemplos migrados a últimas versiones de Room y a AndroidX (room 2.0.0, rxkotlin 2.1.0, rxandroid 2.0.1)
- pasos: dependencias → entidad con @Entity/@PrimaryKey (data class Task) → DAO con @Dao, @Query, @Insert, @Update, @Delete (Flowable vía RxJava) → @Database abstracta → instancia en Application custom con Room.databaseBuilder
