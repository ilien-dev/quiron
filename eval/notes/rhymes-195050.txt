- DEV goal: open, collaborative; code open source (https://github.com/thepracticaldev/dev.to) + API (https://dev.to/api/)
- API keys generated from account settings: https://dev.to/settings/account
- public endpoints need no auth, e.g. https://dev.to/api/articles
- 3 auth methods: API keys (public+private), OAuth2 (private testing, some endpoints, for third-party apps), HTTP session (frontend-only endpoints)
- history: built pre-open-source for internal use, gradually opened, keys added later
- API v0 in beta; promise: no breaking changes, quirks stay until next version; no formal deprecation policy yet
- resources: articles, comments, chat channels, videos, podcasts, tags, listings, analytics (private testing), users
- edge cached -> may serve stale data; some heavy endpoints cached server side too
- needs work: bugs, missing resources/fields, docs, caching
- notable bug: https://github.com/thepracticaldev/dev.to/issues/2250
- feature requests: tag filtering (issues/3654), series CRUD (issues/3669), CORS for public endpoints (issues/4195), video upload (issues/4419) — all under https://github.com/thepracticaldev/dev.to/issues/
- docs https://docs.dev.to/api/: YAML, OpenAPI 3.0, HTML autogenerated each deploy; most endpoints undocumented; meta issue https://github.com/thepracticaldev/dev.to/issues/4474
- API changes announced at https://dev.to/t/changelog
