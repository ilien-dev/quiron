# Acortar URL + Código QR, en Python

Los acortadores de URL están en todas partes: los usamos en redes sociales, en campañas de marketing y en mensajes de texto. Y casi siempre van acompañados de un código QR para escanear desde el móvil. En este post vamos a construir uno propio con Python, Flask y SQLite, y a generar el QR de cada enlace.

## Qué vamos a construir

Una mini-aplicación con tres funciones:

1. **Acortar** una URL larga y devolver un código corto.
2. **Redirigir** `/abc123` a la URL original.
3. **Generar un QR** en PNG para cualquier enlace corto.

Necesitamos dos dependencias:

```bash
pip install flask qrcode[pil]
```

## Paso 1: la base de datos

Usamos SQLite porque viene incluido con Python y no requiere servidor. La tabla guarda el código corto y la URL original:

```python
import sqlite3

DB = "urls.db"

def init_db():
    with sqlite3.connect(DB) as con:
        con.execute("""
            CREATE TABLE IF NOT EXISTS urls (
                code TEXT PRIMARY KEY,
                url  TEXT NOT NULL
            )
        """)
```

## Paso 2: generar códigos cortos

Para el código no conviene usar un contador secuencial, porque sería fácil adivinar los enlaces de otros. El módulo `secrets` nos da valores aleatorios seguros:

```python
import secrets

def nuevo_codigo():
    return secrets.token_urlsafe(6)  # ~8 caracteres alfanuméricos
```

Con 8 caracteres base64 hay más de 2^48 combinaciones, así que las colisiones son muy improbables. Aun así, si se produce una, la base de datos lo detectará porque `code` es `PRIMARY KEY`, y podríamos reintentar.

## Paso 3: la API con Flask

```python
from flask import Flask, request, redirect, abort, jsonify

app = Flask(__name__)

@app.post("/acortar")
def acortar():
    url = request.form.get("url", "").strip()
    if not url.startswith(("http://", "https://")):
        return jsonify(error="URL no válida"), 400

    code = nuevo_codigo()
    with sqlite3.connect(DB) as con:
        con.execute("INSERT INTO urls (code, url) VALUES (?, ?)", (code, url))

    return jsonify(corta=request.host_url + code), 201

@app.get("/<code>")
def redirigir(code):
    with sqlite3.connect(DB) as con:
        fila = con.execute(
            "SELECT url FROM urls WHERE code = ?", (code,)
        ).fetchone()
    if fila is None:
        abort(404)
    return redirect(fila[0], code=302)
```

Validar el esquema (`http://` o `https://`) evita que alguien guarde enlaces `javascript:` o de otros protocolos peligrosos.

## Paso 4: el código QR

La librería `qrcode` hace casi todo el trabajo. Esta ruta devuelve la imagen PNG directamente:

```python
from io import BytesIO
import qrcode
from flask import send_file

@app.get("/qr/<code>")
def qr(code):
    with sqlite3.connect(DB) as con:
        existe = con.execute(
            "SELECT 1 FROM urls WHERE code = ?", (code,)
        ).fetchone()
    if existe is None:
        abort(404)

    img = qrcode.make(request.host_url + code)
    buf = BytesIO()
    img.save(buf, format="PNG")
    buf.seek(0)
    return send_file(buf, mimetype="image/png")
```

Si solo necesitas el QR en un fichero, sin servidor, basta con esto:

```python
import qrcode

qrcode.make("https://dev.to").save("qr.png")
```

Una nota útil: en la ruta del QR comprobamos que el código exista antes de generar la imagen. Así no creamos QR apuntando a enlaces inexistentes.

## Paso 5: arrancarlo

```python
if __name__ == "__main__":
    init_db()
    app.run(debug=True)
```

Ahora puedes probarlo:

```bash
curl -X POST -F "url=https://dev.to" http://127.0.0.1:5000/acortar
# {"corta": "http://127.0.0.1:5000/Xk3j9Qw"}

curl -L http://127.0.0.1:5000/Xk3j9Qw   # redirige a dev.to
```

Y abre `http://127.0.0.1:5000/qr/Xk3j9Qw` en el navegador para ver el código QR.

## Lo que dejo fuera

Este código sirve para aprender, pero no es para producción tal cual. Antes de publicarlo habría que añadir:

- **Límite de peticiones** por IP, para evitar abusos.
- **Contar clics** en una tabla aparte, lo que suele ser la razón principal de usar un acortador.
- **Un servidor WSGI** como Gunicorn en lugar del servidor de desarrollo de Flask.
- **Gestión de conexiones**: el `with sqlite3.connect()` hace commit pero no cierra la conexión, así que en producción conviene usar un pool o cerrarla explícitamente.
- **Comprobación de URLs maliciosas** si el servicio es público.
