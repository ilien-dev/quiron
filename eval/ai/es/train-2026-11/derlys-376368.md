¡Bienvenido de nuevo! En el [primer tutorial](#) vimos qué es **Kikstart UI** y por qué puede ahorrarte horas al construir interfaces en Angular. Hoy toca ensuciarse las manos: vamos a crear un proyecto desde cero, instalar la librería y mostrar nuestro primer componente en pantalla.

## Requisitos previos

Antes de empezar, asegúrate de tener instalado lo siguiente:

- **Node.js** (versión LTS recomendada)
- **npm** o **yarn**
- **Angular CLI**

Puedes comprobar tus versiones con:

```bash
node -v
npm -v
ng version
```

Si todavía no tienes Angular CLI, instálalo de forma global:

```bash
npm install -g @angular/cli
```

## Paso 1: Crear un nuevo proyecto de Angular

Vamos a generar un proyecto limpio para trabajar sin interferencias:

```bash
ng new kikstart-demo --routing --style=scss
cd kikstart-demo
```

Usamos `--routing` porque en próximos tutoriales crearemos varias páginas, y `--style=scss` porque nos dará más flexibilidad a la hora de personalizar estilos.

Arranca el servidor de desarrollo para confirmar que todo funciona:

```bash
ng serve
```

Abre `http://localhost:4200` y deberías ver la página de bienvenida de Angular. Detén el servidor con `Ctrl + C` y sigamos.

## Paso 2: Instalar Kikstart UI

Kikstart UI se apoya en Bootstrap para su sistema de estilos, así que instalaremos ambos paquetes:

```bash
npm install @kikstart/ui bootstrap
```

> 💡 **Consejo:** revisa la página del paquete en npm para confirmar qué versión de Kikstart UI es compatible con tu versión de Angular. Mantener ambas alineadas te evitará errores de dependencias.

## Paso 3: Importar los estilos

Abre el archivo `src/styles.scss` y añade la importación de Bootstrap:

```scss
@import 'bootstrap/scss/bootstrap';
```

Con esto, todos los componentes de Kikstart UI tendrán la base visual que necesitan. Más adelante veremos cómo sobrescribir variables de Bootstrap para adaptar los colores a tu marca.

## Paso 4: Registrar el módulo

Ahora debemos decirle a Angular que queremos usar los componentes de Kikstart UI. Abre `src/app/app.module.ts` e importa el módulo:

```typescript
import { NgModule } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { UiModule } from '@kikstart/ui';

import { AppRoutingModule } from './app-routing.module';
import { AppComponent } from './app.component';

@NgModule({
  declarations: [AppComponent],
  imports: [
    BrowserModule,
    AppRoutingModule,
    UiModule,
  ],
  bootstrap: [AppComponent],
})
export class AppModule {}
```

Si tu proyecto usa **componentes standalone** (el valor por defecto en las versiones recientes de Angular), importa el módulo directamente en el array `imports` del componente donde lo vayas a usar.

## Paso 5: Nuestro primer componente

Llegó el momento de la verdad. Reemplaza el contenido de `src/app/app.component.html` por lo siguiente:

```html
<ui-card>
  <h2>¡Hola, Kikstart UI!</h2>
  <p>Si ves esta tarjeta con estilos, la instalación fue un éxito. 🎉</p>
</ui-card>
```

Vuelve a levantar el servidor:

```bash
ng serve
```

Recarga el navegador y deberías ver una tarjeta con estilo aplicado. ¡Enhorabuena, Kikstart UI ya forma parte de tu proyecto!

## Solución de problemas comunes

**"'ui-card' is not a known element"**
Este error casi siempre significa que el módulo no se importó correctamente. Revisa que `UiModule` esté en el array `imports` del módulo o componente correcto.

**Los componentes aparecen sin estilos**
Verifica que la importación de Bootstrap esté en `styles.scss` y que ese archivo figure en la sección `styles` de tu `angular.json`.

**Conflictos de dependencias al instalar**
Si npm muestra errores de *peer dependencies*, probablemente haya una incompatibilidad de versiones con Angular. Instala la versión de Kikstart UI que corresponda a tu versión de Angular en lugar de forzar la instalación con `--force`.

5. Renderizado nuestro primer componente.
