# Tutorial 2: Instalación de Kikstart UI

En el [tutorial anterior](#) instalamos Angular CLI y creamos nuestro primer proyecto. Ahora vamos a darle un poco de estilo añadiendo **Kikstart UI**, una librería de componentes para Angular que nos permitirá construir interfaces atractivas sin tener que escribir todo el CSS desde cero.

## ¿Qué es Kikstart UI?

Kikstart UI es una colección de componentes de interfaz para Angular construida sobre **Bootstrap**. Incluye elementos listos para usar como barras de navegación, layouts, tarjetas, formularios e iconos, y además facilita el cambio de temas mediante Bootswatch.

Su objetivo es que puedas tener una aplicación con buena apariencia en pocos minutos y centrarte en la lógica de tu proyecto.

## Requisitos

Antes de empezar, asegúrate de tener:

- Node.js y npm instalados.
- Angular CLI instalado de forma global.
- Un proyecto Angular creado (si seguiste el tutorial 1, usaremos `mi-primera-app`).

Puedes comprobar las versiones con:

```bash
node -v
ng version
```

## Paso 1: abrir el proyecto

Entra en la carpeta del proyecto desde la terminal:

```bash
cd mi-primera-app
```

Si el servidor de desarrollo está en marcha, detenlo con `Ctrl + C`.

## Paso 2: instalar Kikstart UI

La forma más sencilla es usar `ng add`, que instala la librería y además configura el proyecto automáticamente:

```bash
ng add @kikstart-ui/schematics
```

Este comando se encarga de:

- Instalar los paquetes necesarios de Kikstart UI.
- Añadir Bootstrap y los estilos de Bootswatch.
- Registrar los estilos en el archivo `angular.json`.

Si prefieres hacerlo a mano, puedes instalar los paquetes con npm:

```bash
npm install @kikstart-ui/ui bootstrap bootswatch
```

Y luego añadir los estilos en `angular.json`, dentro de la sección `styles`:

```json
"styles": [
  "node_modules/bootswatch/dist/darkly/bootstrap.min.css",
  "src/styles.css"
]
```

En este ejemplo usamos el tema **Darkly**, pero puedes elegir cualquier otro de Bootswatch, como `flatly`, `lux` o `minty`.

## Paso 3: importar el módulo

Abre `src/app/app.module.ts` e importa el módulo de Kikstart UI:

```typescript
import { NgModule } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { UiModule } from '@kikstart-ui/ui';

import { AppComponent } from './app.component';

@NgModule({
  declarations: [AppComponent],
  imports: [BrowserModule, UiModule],
  bootstrap: [AppComponent],
})
export class AppModule {}
```

## Paso 4: probar un componente

Reemplaza el contenido de `src/app/app.component.html` por lo siguiente:

```html
<div class="container py-5">
  <div class="card">
    <div class="card-body">
      <h1 class="card-title">¡Kikstart UI funcionando!</h1>
      <p class="card-text">Nuestra aplicación ya tiene estilos de Bootstrap.</p>
      <button class="btn btn-primary">Empezar</button>
    </div>
  </div>
</div>
```

## Paso 5: levantar el servidor

```bash
ng serve --open
```

Si todo salió bien, verás una tarjeta con el tema oscuro de Darkly en `http://localhost:4200`.

## Problemas comunes

- **Los estilos no se aplican**: revisa que la ruta en `angular.json` sea correcta y reinicia `ng serve`, ya que los cambios en ese archivo no se recargan en caliente.
- **Error de versiones**: asegúrate de que la versión de Kikstart UI sea compatible con tu versión de Angular.

## Conclusión

Ya tenemos Kikstart UI instalado y configurado en nuestro proyecto. En el próximo tutorial usaremos sus componentes de layout para crear la estructura de nuestra aplicación, con una barra de navegación y varias páginas. ¡Nos vemos!
