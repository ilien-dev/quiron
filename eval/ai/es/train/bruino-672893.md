# Acortar URLs y Generar Códigos QR con Python

En la era digital, acortar URLs y generar códigos QR son funcionalidades comunes en muchas aplicaciones. La buena noticia es que Python hace ambas tareas increíblemente sencillas con las librerías adecuadas.

## Por qué acortar URLs

Una URL larga es fea, difícil de compartir y poco profesional. Las URLs acortadas son más manejables, especialmente en medios limitados como redes sociales o mensajes de texto. Además, los códigos QR permiten que los usuarios accedan a contenido con solo escanear con sus teléfonos.

## Acortar URLs con Python

Para acortar URLs, podemos usar servicios en línea. La librería `requests` nos ayuda a comunicarnos con estos servicios.

Un enfoque simple es usar TinyURL:

```python
import requests

def acortar_url(url):
    api_url = f"https://tinyurl.com/api-create.php?url={url}"
    respuesta = requests.get(api_url)
    return respuesta.text
```

También está bit.ly, que ofrece URLs más personalizables. Para usarlo necesitas una API key:

```python
import requests

def acortar_con_bitly(url, token):
    headers = {"Authorization": f"Bearer {token}"}
    datos = {"long_url": url}
    respuesta = requests.post(
        "https://api-ssl.bitly.com/v4/shorten",
        headers=headers,
        json=datos
    )
    return respuesta.json()["link"]
```

## Generar códigos QR

Para generar códigos QR, usamos la librería `qrcode`:

```bash
pip install qrcode[pil]
```

Crear un código QR es trivial:

```python
import qrcode

def generar_qr(url, nombre_archivo):
    qr = qrcode.QRCode(
        version=1,
        error_correction=qrcode.constants.ERROR_CORRECT_L,
        box_size=10,
        border=4,
    )
    qr.add_data(url)
    qr.make(fit=True)
    imagen = qr.make_image(fill_color="black", back_color="white")
    imagen.save(nombre_archivo)
```

## Combinando ambas

Ahora podemos crear una función que acorte la URL y genere un código QR:

```python
import requests
import qrcode

def url_y_qr(url_larga, archivo_qr):
    # Acortar
    api_url = f"https://tinyurl.com/api-create.php?url={url_larga}"
    url_corta = requests.get(api_url).text
    
    # Generar QR
    qr = qrcode.QRCode(version=1, box_size=10, border=4)
    qr.add_data(url_corta)
    qr.make(fit=True)
    qr.make_image().save(archivo_qr)
    
    return url_corta

# Usar
enlace_corto = url_y_qr("https://ejemplo.com/articulo/muy/largo", "codigo.png")
print(f"URL corta: {enlace_corto}")
```

## Consideraciones importantes

Cuando uses servicios de acortamiento, verifica que sean confiables. TinyURL y bit.ly son establos y seguros. Si tu aplicación es profesional, considera usar un servicio con opciones de analíticas para rastrear clics.

Los códigos QR generados con `qrcode` funcionan bien para URLs, pero también puedes usarlos para texto, contactos o eventos. La librería es flexible.

Con Python, acortar URLs y generar códigos QR es cosa de minutos. Estas funcionalidades son útiles en aplicaciones web, sistemas de ticketing, códigos promocionales y más. Las herramientas están ahí, listas para usar.
