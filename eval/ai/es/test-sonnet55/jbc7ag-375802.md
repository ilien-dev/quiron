# Obtener un String separado de una lista en Kotlin: joinToString()

Una necesidad muy común al programar es convertir una colección en un único `String`: mostrar una lista de etiquetas, generar un CSV sencillo, construir un mensaje de log o armar una consulta. En Kotlin hay una función de la librería estándar que resuelve esto con muy poco código: `joinToString()`.

## El caso básico

Imagina que tienes una lista de frutas y quieres mostrarlas separadas por comas:

```kotlin
val frutas = listOf("manzana", "pera", "uva")

println(frutas.joinToString())
// manzana, pera, uva
```

Sin ningún parámetro, el separador por defecto es `", "` (coma y espacio). Fíjate en que no queda ninguna coma sobrante al final, algo que sí suele pasar cuando se concatena a mano dentro de un bucle.

## Cambiar el separador

El primer parámetro es el separador, y puede ser cualquier cadena:

```kotlin
println(frutas.joinToString(" | "))
// manzana | pera | uva

println(frutas.joinToString(separator = "-"))
// manzana-pera-uva

println(frutas.joinToString(separator = "\n"))
// manzana
// pera
// uva
```

Usar el nombre del parámetro (`separator = ...`) hace el código más legible, sobre todo cuando se combinan varios argumentos.

## Prefijo y postfijo

Con `prefix` y `postfix` envuelves el resultado en los caracteres que necesites:

```kotlin
println(frutas.joinToString(separator = ", ", prefix = "[", postfix = "]"))
// [manzana, pera, uva]
```

Es muy útil para imitar la representación de una lista, generar fragmentos de SQL como `(1, 2, 3)` o añadir comillas alrededor del conjunto.

## Limitar el número de elementos

Si la lista es larga y solo quieres mostrar una parte, usa `limit` y `truncated`:

```kotlin
val numeros = (1..100).toList()

println(numeros.joinToString(limit = 5))
// 1, 2, 3, 4, 5, ...

println(numeros.joinToString(limit = 5, truncated = "…y más"))
// 1, 2, 3, 4, 5, …y más
```

Por defecto, cuando se supera el límite se añade `"..."`. Con `truncated` puedes personalizar ese texto. Es perfecto para logs o para previsualizaciones en la interfaz.

## Transformar cada elemento

El último parámetro es `transform`, una lambda que se aplica a cada elemento antes de unirlo. Esto permite trabajar con listas de cualquier tipo, no solo de `String`:

```kotlin
data class Usuario(val nombre: String, val edad: Int)

val usuarios = listOf(
    Usuario("Ana", 28),
    Usuario("Luis", 35),
    Usuario("Marta", 41)
)

println(usuarios.joinToString { it.nombre })
// Ana, Luis, Marta

println(usuarios.joinToString(separator = "; ") { "${it.nombre} (${it.edad})" })
// Ana (28); Luis (35); Marta (41)
```

Al ser el último parámetro, puedes usar la sintaxis de lambda al final, como en los ejemplos anteriores. Así te ahorras un `map { ... }` intermedio y la creación de una lista temporal.

## Con números y otros tipos

No hace falta que los elementos sean cadenas. Si no pasas `transform`, Kotlin llama a `toString()` en cada uno:

```kotlin
val ids = listOf(10, 20, 30)
println(ids.joinToString(","))
// 10,20,30
```

## Otras colecciones

`joinToString()` no es exclusivo de `List`. Está disponible en `Iterable`, `Array` y `Sequence`:

```kotlin
val arreglo = arrayOf("a", "b", "c")
println(arreglo.joinToString("/"))
// a/b/c

val secuencia = generateSequence(1) { it + 1 }.take(4)
println(secuencia.joinToString())
// 1, 2, 3, 4
```

## Elementos nulos

Si la lista contiene `null`, se imprime como el texto `"null"`. Si no lo quieres, filtra antes o usa `transform`:

```kotlin
val datos = listOf("a", null, "c")

println(datos.joinToString())
// a, null, c

println(datos.filterNotNull().joinToString())
// a, c

println(datos.joinToString { it ?: "-" })
// a, -, c
```

## ¿Y si ya tengo un StringBuilder?

Existe la variante `joinTo()`, que añade el resultado a un `Appendable` (como un `StringBuilder`) en lugar de crear un nuevo `String`:

```kotlin
val sb = StringBuilder("Frutas: ")
frutas.joinTo(sb, separator = " y ")
println(sb)
// Frutas: manzana y pera y uva
```

## Resumen

La firma completa, con todos sus valores por defecto, es:

```kotlin
joinToString(
    separator = ", ",
    prefix = "",
    postfix = "",
    limit = -1,
    truncated = "...",
    transform = null
)
```

Con `joinToString()` evitas bucles manuales, comas sobrantes y código repetitivo. Recuerda estas ideas clave:

- `separator` define lo que va entre elementos.
- `prefix` y `postfix` envuelven el resultado.
- `limit` y `truncated` recortan listas largas.
- `transform` convierte cada elemento antes de unirlo.
- Funciona con `List`, `Array`, `Sequence` y cualquier `Iterable`.

La próxima vez que te descubras escribiendo un `for` para concatenar cadenas, piensa en `joinToString()`: es más corto, más claro y menos propenso a errores.
