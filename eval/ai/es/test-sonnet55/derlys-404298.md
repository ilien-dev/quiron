# Tutorial: Aplicaciones de Angular CLI con bootstrap

Angular te da estructura, enrutamiento, formularios y un sistema de componentes sólido. Lo que no te da es un diseño visual listo para usar. Ahí entra Bootstrap: una librería de estilos madura, con una rejilla flexible y decenas de componentes que funcionan bien desde el primer minuto.

En este tutorial crearemos una aplicación con Angular CLI y la integraremos con Bootstrap 5 paso a paso. Al final tendrás una barra de navegación, un listado de tarjetas responsive, un formulario con validación y componentes interactivos mediante `ng-bootstrap`.

## Requisitos

- Node.js en una versión LTS reciente
- Conocimientos básicos de TypeScript y HTML
- Un editor de código (VS Code, por ejemplo)

Instala Angular CLI de forma global si todavía no lo tienes:

```bash
npm install -g @angular/cli
ng version
```

## 1. Crear el proyecto

```bash
ng new tienda-bootstrap --style=scss
cd tienda-bootstrap
```

El CLI te hará un par de preguntas (SSR, entre otras). Para este tutorial puedes responder que no a SSR. Usamos `--style=scss` porque más adelante personalizaremos Bootstrap con variables de Sass.

Comprueba que todo funciona:

```bash
ng serve
```

Abre `http://localhost:4200` y deberías ver la página de bienvenida.

> **Nota:** según la versión de Angular, los archivos del componente raíz se llaman `app.component.ts` o simplemente `app.ts`. Los ejemplos de abajo funcionan igual en ambos casos; solo cambia el nombre del archivo y de la clase.

## 2. Instalar Bootstrap

Bootstrap se distribuye por npm. Instalamos también Popper, que necesitan los componentes con posicionamiento (tooltips, dropdowns, popovers):

```bash
npm install bootstrap @popperjs/core
```

Con esto tienes los estilos y el JavaScript en `node_modules`. Ahora toca decirle a Angular que los use.

## 3. Incluir los estilos

Hay dos formas habituales.

### Opción A: desde `angular.json`

Es la más simple. Añade el CSS de Bootstrap al array `styles` del proyecto:

```json
"styles": [
  "node_modules/bootstrap/dist/css/bootstrap.min.css",
  "src/styles.scss"
]
```

Reinicia `ng serve` para que tome el cambio.

### Opción B: importar el Sass (recomendada)

Si quieres personalizar el tema, importa el código fuente de Bootstrap en `src/styles.scss`:

```scss
// Variables propias ANTES de importar Bootstrap
$primary: #6f42c1;
$border-radius: 0.5rem;
$font-family-sans-serif: "Inter", system-ui, sans-serif;

@import "bootstrap/scss/bootstrap";
```

Al sobrescribir variables como `$primary`, todos los componentes (botones, enlaces, alertas, badges) adoptan tu color de marca sin tocar una sola clase.

Ten en cuenta que, con versiones recientes de Sass, puedes ver avisos de deprecación relacionados con `@import`. Son advertencias, no errores, y Bootstrap 5.3 sigue usando este mecanismo.

## 4. Verificar la instalación

Sustituye el contenido de `src/app/app.html` (o la plantilla de tu componente raíz) por algo mínimo:

```html
<div class="container py-5">
  <h1 class="display-5">Hola, Bootstrap</h1>
  <button class="btn btn-primary">Botón primario</button>
</div>
```

Si ves un título grande y un botón con tu color, la integración funciona.

## 5. Una barra de navegación

Creemos un componente para la navegación:

```bash
ng generate component navbar
```

En `navbar.html`:

```html
<nav class="navbar navbar-expand-lg bg-body-tertiary border-bottom">
  <div class="container">
    <a class="navbar-brand fw-bold" href="#">Mi Tienda</a>

    <button
      class="navbar-toggler"
      type="button"
      (click)="colapsado = !colapsado"
      aria-label="Mostrar navegación">
      <span class="navbar-toggler-icon"></span>
    </button>

    <div class="collapse navbar-collapse" [class.show]="!colapsado">
      <ul class="navbar-nav ms-auto">
        <li class="nav-item"><a class="nav-link active" href="#">Inicio</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Productos</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Contacto</a></li>
      </ul>
    </div>
  </div>
</nav>
```

Y en `navbar.ts`:

```ts
import { Component } from '@angular/core';

@Component({
  selector: 'app-navbar',
  templateUrl: './navbar.html',
})
export class Navbar {
  colapsado = true;
}
```

Fíjate en que controlamos el menú desplegable con una propiedad de Angular y `[class.show]`, en lugar de depender del JavaScript de Bootstrap. Esto evita conflictos entre el DOM que gestiona Angular y el que manipula Bootstrap, un problema clásico que veremos en las buenas prácticas.

## 6. Rejilla y tarjetas responsive

Vamos a mostrar un catálogo. Define los datos en el componente raíz:

```ts
import { Component } from '@angular/core';
import { Navbar } from './navbar/navbar';

interface Producto {
  id: number;
  nombre: string;
  precio: number;
  descripcion: string;
}

@Component({
  selector: 'app-root',
  imports: [Navbar],
  templateUrl: './app.html',
})
export class App {
  productos: Producto[] = [
    { id: 1, nombre: 'Teclado mecánico', precio: 89.9, descripcion: 'Switches táctiles, layout ISO.' },
    { id: 2, nombre: 'Ratón ergonómico', precio: 49.5, descripcion: 'Diseño vertical, 6 botones.' },
    { id: 3, nombre: 'Monitor 27"', precio: 279, descripcion: 'Panel IPS, resolución QHD.' },
    { id: 4, nombre: 'Webcam HD', precio: 59, descripcion: '1080p con micrófono integrado.' },
  ];
}
```

Y la plantilla `app.html`, usando el control de flujo moderno de Angular (`@for`):

```html
<app-navbar />

<main class="container py-4">
  <h2 class="mb-4">Catálogo</h2>

  <div class="row g-4">
    @for (p of productos; track p.id) {
      <div class="col-12 col-sm-6 col-lg-3">
        <div class="card h-100 shadow-sm">
          <div class="card-body d-flex flex-column">
            <h5 class="card-title">{{ p.nombre }}</h5>
            <p class="card-text text-body-secondary">{{ p.descripcion }}</p>
            <div class="mt-auto d-flex justify-content-between align-items-center">
              <span class="fw-semibold">{{ p.precio }} €</span>
              <button class="btn btn-sm btn-primary">Añadir</button>
            </div>
          </div>
        </div>
      </div>
    }
  </div>
</main>
```

Las clases `col-12 col-sm-6 col-lg-3` hacen que haya una tarjeta por fila en móvil, dos en tabletas y cuatro en escritorio. `h-100` iguala las alturas y `mt-auto` empuja el precio y el botón al fondo de cada tarjeta.

## 7. Formulario con validación

Bootstrap tiene clases de validación (`is-valid`, `is-invalid`, `invalid-feedback`) que encajan muy bien con los formularios reactivos de Angular.

```bash
ng generate component contacto
```

`contacto.ts`:

```ts
import { Component, inject } from '@angular/core';
import { FormBuilder, ReactiveFormsModule, Validators } from '@angular/forms';

@Component({
  selector: 'app-contacto',
  imports: [ReactiveFormsModule],
  templateUrl: './contacto.html',
})
export class Contacto {
  private fb = inject(FormBuilder);

  form = this.fb.nonNullable.group({
    nombre: ['', [Validators.required, Validators.minLength(3)]],
    email: ['', [Validators.required, Validators.email]],
  });

  invalido(campo: 'nombre' | 'email'): boolean {
    const c = this.form.controls[campo];
    return c.invalid && (c.touched || c.dirty);
  }

  enviar() {
    if (this.form.invalid) {
      this.form.markAllAsTouched();
      return;
    }
    console.log(this.form.getRawValue());
  }
}
```

`contacto.html`:

```html
<form class="container py-4" style="max-width: 480px" [formGroup]="form" (ngSubmit)="enviar()">
  <div class="mb-3">
    <label for="nombre" class="form-label">Nombre</label>
    <input id="nombre" class="form-control" formControlName="nombre"
           [class.is-invalid]="invalido('nombre')" />
    <div class="invalid-feedback">Escribe al menos 3 caracteres.</div>
  </div>

  <div class="mb-3">
    <label for="email" class="form-label">Correo electrónico</label>
    <input id="email" type="email" class="form-control" formControlName="email"
           [class.is-invalid]="invalido('email')" />
    <div class="invalid-feedback">Introduce un correo válido.</div>
  </div>

  <button class="btn btn-primary" type="submit">Enviar</button>
</form>
```

El mensaje de `invalid-feedback` solo se muestra cuando el campo tiene la clase `is-invalid`, así que no necesitas `@if` adicionales. Angular decide cuándo, Bootstrap decide cómo se ve.

## 8. Componentes interactivos con ng-bootstrap

Para modales, dropdowns, tooltips o carruseles, la opción más limpia es usar una librería que reimplemente la lógica de Bootstrap en Angular, sin jQuery ni manipulación directa del DOM. La más conocida es `ng-bootstrap`:

```bash
ng add @ng-bootstrap/ng-bootstrap
```

Con componentes standalone, importas solo lo que usas. Por ejemplo, una alerta que se puede cerrar:

```ts
import { Component } from '@angular/core';
import { NgbAlert } from '@ng-bootstrap/ng-bootstrap';

@Component({
  selector: 'app-aviso',
  imports: [NgbAlert],
  template: `
    <ngb-alert type="success" (closed)="visible = false">
      ¡Producto añadido al carrito!
    </ngb-alert>
  `,
})
export class Aviso {
  visible = true;
}
```

Y un modal con `NgbModal`:

```ts
import { Component, inject, TemplateRef } from '@angular/core';
import { NgbModal } from '@ng-bootstrap/ng-bootstrap';

@Component({
  selector: 'app-confirmar',
  template: `
    <button class="btn btn-outline-danger" (click)="abrir(contenido)">Vaciar carrito</button>

    <ng-template #contenido let-modal>
      <div class="modal-header">
        <h5 class="modal-title">Confirmar</h5>
      </div>
      <div class="modal-body">¿Seguro que quieres vaciar el carrito?</div>
      <div class="modal-footer">
        <button class="btn btn-secondary" (click)="modal.dismiss()">Cancelar</button>
        <button class="btn btn-danger" (click)="modal.close('ok')">Vaciar</button>
      </div>
    </ng-template>
  `,
})
export class Confirmar {
  private modal = inject(NgbModal);

  abrir(contenido: TemplateRef<unknown>) {
    this.modal.open(contenido).result.then(
      () => console.log('Carrito vaciado'),
      () => console.log('Cancelado'),
    );
  }
}
```

Si usas `ng-bootstrap`, no necesitas cargar `bootstrap.bundle.js`: solo el CSS. Revisa también la tabla de compatibilidad de versiones en su documentación, porque cada versión de la librería exige una versión concreta de Angular y de Bootstrap.

## 9. Buenas prácticas

1. **No mezcles el JS de Bootstrap con Angular.** Si añades `bootstrap.bundle.js` y usas `data-bs-toggle` en plantillas que Angular renderiza dinámicamente (`@if`, `@for`), los listeners pueden perderse o duplicarse. Usa `ng-bootstrap` o controla el estado con propiedades de Angular, como hicimos en la navbar.
2. **Personaliza con variables, no con `!important`.** Sobrescribir `$primary` y otras variables de Sass es más mantenible que parchear estilos uno a uno.
3. **Importa solo lo que necesitas.** En lugar de `@import "bootstrap/scss/bootstrap"`, puedes importar módulos concretos (`functions`, `variables`, `mixins`, `buttons`, `card`…) para reducir el tamaño del CSS final.
4. **Cuida la accesibilidad.** Bootstrap ofrece buenas bases, pero tú sigues siendo responsable de `aria-label`, de asociar `label` con `input` y de mantener contraste suficiente al cambiar colores.
5. **Aprovecha el modo oscuro.** Bootstrap 5.3 soporta `data-bs-theme="dark"` en cualquier elemento. Puedes alternarlo con un `signal` y un `[attr.data-bs-theme]` en el `<html>` o en tu contenedor raíz.
6. **Construye y mide.** Ejecuta `ng build` y revisa los tamaños de los bundles. Si el CSS crece demasiado, es la señal para importar parcialmente Bootstrap.

## Conclusión

Integrar Bootstrap en un proyecto de Angular CLI es sencillo: instalas el paquete, enlazas los estilos y empiezas a usar clases. La parte que merece más atención está en los detalles: personalizar mediante Sass, evitar choques entre el JavaScript de Bootstrap y el renderizado de Angular, y apoyarte en `ng-bootstrap` cuando necesites componentes interactivos.

Con lo visto, ya tienes la base para construir interfaces completas: navegación, catálogos responsive, formularios con validación y diálogos. El siguiente paso natural es añadir enrutamiento con `provideRouter`, conectar los productos a una API con `HttpClient` y convertir el tema en algo propio con tus variables de diseño.
