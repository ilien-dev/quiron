# Tutorial 1: Instalando Angular CLI

Bienvenido al primer tutorial de esta serie sobre Angular. Antes de escribir componentes, servicios o rutas, necesitamos preparar el entorno de trabajo. La herramienta central es **Angular CLI**, la interfaz de línea de comandos oficial del framework.

En este post veremos qué es Angular CLI, cómo instalarlo paso a paso y cómo crear y ejecutar tu primera aplicación.

## ¿Qué es Angular CLI?

Angular CLI es una herramienta que automatiza las tareas más habituales del desarrollo con Angular:

- **Crear proyectos** con una estructura y configuración listas para usar.
- **Generar código**: componentes, servicios, pipes, guards y más, con un solo comando.
- **Servir la aplicación** en local con recarga automática al guardar cambios.
- **Compilar para producción** con optimizaciones aplicadas.
- **Ejecutar pruebas** y **actualizar** el proyecto a nuevas versiones de Angular.

Se puede trabajar sin el CLI, pero sería como montar un mueble sin herramientas: posible, aunque mucho más lento.

## Requisito previo: Node.js y npm

Angular CLI se distribuye como un paquete de npm, así que primero necesitas **Node.js**, que ya incluye **npm**.

1. Ve a [nodejs.org](https://nodejs.org) y descarga la versión **LTS** (soporte a largo plazo). Es la opción más estable y la que Angular soporta oficialmente.
2. Instálala con las opciones por defecto.
3. Abre una terminal y comprueba que todo funciona:

```bash
node -v
npm -v
```

Si ambos comandos muestran un número de versión, estás listo. Si tu versión de Node es muy antigua, Angular CLI te avisará durante la instalación; en ese caso, actualízala.

> 💡 **Consejo:** si trabajas con varios proyectos que requieren distintas versiones de Node, considera usar un gestor de versiones como **nvm** (macOS/Linux) o **nvm-windows**.

## Instalando Angular CLI

Con Node.js listo, instala Angular CLI de forma global:

```bash
npm install -g @angular/cli
```

La opción `-g` hace que el comando `ng` esté disponible desde cualquier carpeta del sistema.

Verifica la instalación:

```bash
ng version
```

Verás un resumen con la versión del CLI, de Node y del sistema operativo. La primera vez, el CLI puede preguntarte si quieres compartir datos de uso anónimos con el equipo de Angular; responde lo que prefieras.

### Problema frecuente en Windows

Si usas PowerShell y aparece un error indicando que la ejecución de scripts está deshabilitada, ejecuta:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

Esto permite ejecutar scripts locales como `ng` solo para tu usuario.

### Problema frecuente en macOS/Linux

Si recibes errores de permisos (`EACCES`), evita usar `sudo` con npm. La solución recomendada es instalar Node mediante **nvm**, que coloca los paquetes globales en tu carpeta de usuario.

## Creando tu primera aplicación

Ahora viene lo divertido. Sitúate en la carpeta donde guardas tus proyectos y ejecuta:

```bash
ng new mi-primera-app
```

El CLI te hará algunas preguntas:

- **Formato de estilos:** CSS, SCSS, Sass o Less. Si no estás seguro, elige **CSS** o **SCSS**.
- **Server-Side Rendering (SSR):** por ahora puedes responder **No**; lo veremos en tutoriales futuros.

Después, el CLI creará la estructura del proyecto e instalará las dependencias. Puede tardar un par de minutos.

## Ejecutando la aplicación

Entra en la carpeta del proyecto y levanta el servidor de desarrollo:

```bash
cd mi-primera-app
ng serve
```

Abre tu navegador en **http://localhost:4200** y verás la página de bienvenida de Angular. 🎉

Prueba a abrir `src/app/app.html` (o `app.component.html` en proyectos más antiguos), cambia algún texto y guarda. El navegador se actualizará automáticamente.

Para abrir el navegador directamente al iniciar el servidor, usa:

```bash
ng serve --open
```

## Comandos útiles para recordar

| Comando | Qué hace |
|---|---|
| `ng new <nombre>` | Crea un proyecto nuevo |
| `ng serve` | Inicia el servidor de desarrollo |
| `ng generate component <nombre>` | Genera un componente |
| `ng build` | Compila para producción |
| `ng test` | Ejecuta las pruebas |
| `ng update` | Actualiza Angular y sus dependencias |

## Conclusión

Ya tienes Node.js, Angular CLI y tu primera aplicación funcionando. Es un primer paso pequeño, pero sienta las bases de todo lo que construiremos.
