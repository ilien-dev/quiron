# Obtener un String separado de una lista en Kotlin: joinToString()

Una tarea muy común al trabajar con colecciones en Kotlin es convertir una lista de elementos en un único `String`, separado por comas, saltos de línea, o cualquier otro delimitador. En Java, esto normalmente requería recurrir a `StringBuilder` o a la clase `String.join()`, pero Kotlin ofrece una función de extensión mucho más flexible y expresiva: `joinToString()`.

## Uso básico

Supongamos que tenemos una lista de nombres:

```kotlin
val nombres = listOf("Ana", "Luis", "Marta")
val resultado = nombres.joinToString()
println(resultado)
// Ana, Luis, Marta
```

Por defecto, `joinToString()` separa los elementos con `", "` (coma y espacio). No hace falta especificar nada más si ese comportamiento por defecto ya nos sirve.

## Cambiando el separador

Podemos indicar un separador distinto usando el parámetro `separator`:

```kotlin
val resultado = nombres.joinToString(separator = " - ")
println(resultado)
// Ana - Luis - Marta
```

Esto es útil, por ejemplo, para generar rutas de archivos, CSV, o cualquier formato con un delimitador específico:

```kotlin
val partesRuta = listOf("usuarios", "42", "posts")
val ruta = partesRuta.joinToString(separator = "/")
println(ruta)
// usuarios/42/posts
```

## Prefijo y sufijo

`joinToString()` también permite añadir un prefijo y un sufijo al resultado completo, lo cual es muy útil para generar representaciones tipo array o JSON de forma manual:

```kotlin
val numeros = listOf(1, 2, 3, 4)
val resultado = numeros.joinToString(separator = ", ", prefix = "[", postfix = "]")
println(resultado)
// [1, 2, 3, 4]
```

## Limitando la cantidad de elementos

Cuando trabajamos con listas potencialmente muy largas, puede interesarnos mostrar solo los primeros N elementos y truncar el resto. Para eso está el parámetro `limit`, junto con `truncated`:

```kotlin
val letras = listOf("a", "b", "c", "d", "e", "f")
val resultado = letras.joinToString(limit = 3, truncated = "...")
println(resultado)
// a, b, c, ...
```

Si no se especifica `truncated`, Kotlin usa por defecto el string `"..."`, así que en muchos casos ni siquiera hace falta indicarlo explícitamente.

## Transformando los elementos con transform

Quizás la característica más potente de `joinToString()` es el parámetro `transform`, que recibe una función lambda aplicada a cada elemento antes de unirlo al resultado final. Esto evita tener que hacer un `map` previo y luego un `joinToString` por separado:

```kotlin
data class Usuario(val nombre: String, val edad: Int)

val usuarios = listOf(
    Usuario("Ana", 28),
    Usuario("Luis", 34)
)

val resultado = usuarios.joinToString(separator = "; ") { usuario ->
    "${usuario.nombre} (${usuario.edad} años)"
}
println(resultado)
// Ana (28 años); Luis (34 años)
```

Nótese que, al ser el último parámetro de la función, la lambda se puede escribir fuera de los paréntesis, siguiendo la convención de *trailing lambda* de Kotlin.

## Comparando con la alternativa "manual"

Sin `joinToString()`, lograr el mismo resultado requeriría algo como esto:

```kotlin
val sb = StringBuilder()
for ((index, usuario) in usuarios.withIndex()) {
    if (index > 0) sb.append("; ")
    sb.append("${usuario.nombre} (${usuario.edad} años)")
}
val resultado = sb.toString()
```

La diferencia en legibilidad es notable. `joinToString()` encapsula toda esta lógica repetitiva (el manejo del separador entre elementos, la construcción del string) en una sola llamada declarativa.

## joinTo(): la variante que escribe en un Appendable

Existe también una función hermana, `joinTo()`, que en lugar de devolver un nuevo `String`, escribe el resultado directamente en un `Appendable` (como un `StringBuilder` existente). Esto es útil cuando ya estamos construyendo un string más grande y queremos insertar la lista unida en medio de otro contenido, sin crear un `String` intermedio innecesario:

```kotlin
val sb = StringBuilder("Usuarios registrados: ")
usuarios.joinTo(sb, separator = ", ") { it.nombre }
println(sb.toString())
// Usuarios registrados: Ana, Luis
```

## Conclusión

`joinToString()` es una de esas funciones de la biblioteca estándar de Kotlin que, una vez la conoces, terminas usando constantemente. Cubre de forma muy elegante un caso de uso extremadamente común —convertir una colección en un `String` legible—, con suficiente flexibilidad (separador, prefijo, sufijo, límite, transformación) como para adaptarse a la gran mayoría de escenarios sin necesidad de escribir bucles manuales. Si vienes de Java y todavía escribes bucles con `StringBuilder` para esto, dale una oportunidad: seguramente no vuelvas a hacerlo de la forma antigua.
