¡Bienvenido a esta serie de tutoriales de Angular! Antes de escribir componentes, servicios o rutas, necesitamos preparar el entorno. En este primer capítulo instalaremos **Angular CLI**, la herramienta oficial de línea de comandos, y dejaremos una aplicación corriendo en el navegador.

## ¿Qué es Angular CLI?

Angular CLI es la herramienta con la que crearás, desarrollarás y mantendrás tus proyectos Angular. Con un solo comando puedes generar un proyecto completo, levantar un servidor de desarrollo, crear componentes, ejecutar pruebas y compilar para producción. Podrías configurar todo a mano, pero el CLI te ahorra horas de trabajo y aplica las buenas prácticas recomendadas por el equipo de Angular.

## Requisitos previos

Solo necesitas dos cosas:

- **Node.js**: Angular requiere una versión LTS activa o en mantenimiento. Descárgala desde [nodejs.org](https://nodejs.org).
- **npm**: el gestor de paquetes, que se instala junto con Node.js.

Comprueba que los tienes abriendo una terminal:

```bash
node --version
npm --version
```

Si ambos comandos devuelven un número de versión, estás listo. Cada versión de Angular admite versiones concretas de Node.js; si tienes dudas, consulta la [tabla de compatibilidad oficial](https://angular.dev/reference/versions).

## Instalando Angular CLI

Instalaremos el CLI de forma global para que el comando `ng` esté disponible desde cualquier carpeta:

```bash
npm install -g @angular/cli
```

La opción `-g` indica a npm que la instalación es global y no pertenece a un proyecto concreto. El proceso puede tardar un par de minutos.

### Nota para usuarios de Windows

PowerShell bloquea por defecto la ejecución de scripts, y eso impide usar el comando `ng`. Si ves un error de este tipo, ejecuta lo siguiente y vuelve a intentarlo:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

### Nota para macOS y Linux

Si recibes un error de permisos (`EACCES`), evita usar `sudo`. Es mejor instalar Node.js con un gestor de versiones como [nvm](https://github.com/nvm-sh/nvm), que resuelve el problema de raíz.

## Verificando la instalación

Comprueba que todo ha ido bien:

```bash
ng version
```

Verás la versión del CLI junto con la de Node.js y la de tu gestor de paquetes. Si aparece, ¡ya tienes Angular CLI instalado!

## Creando tu primer proyecto

Vamos a probarlo creando una aplicación:

```bash
ng new mi-primera-app
```

El CLI te hará algunas preguntas, como qué formato de estilos prefieres (CSS, SCSS...) o si quieres activar el renderizado en servidor (SSR). Para empezar, acepta las opciones por defecto pulsando Enter. A continuación se creará la estructura de carpetas y se instalarán las dependencias.

## Arrancando el servidor de desarrollo

Entra en la carpeta del proyecto y levanta el servidor:

```bash
cd mi-primera-app
ng serve
```

Cuando termine la compilación, abre `http://localhost:4200` en tu navegador. Verás la página de bienvenida de Angular. 🎉

El servidor vigila tus archivos: cada vez que guardes un cambio, la aplicación se recargará automáticamente. Pruébalo editando `src/app/app.html` y observa el resultado al instante.

## Comandos que usarás a menudo

| Comando | Descripción |
|---|---|
| `ng new <nombre>` | Crea un proyecto nuevo |
| `ng serve` | Levanta el servidor de desarrollo |
| `ng generate component <nombre>` | Genera un componente |
| `ng build` | Compila la aplicación para producción |
| `ng test` | Ejecuta las pruebas unitarias |
| `ng update` | Actualiza Angular y sus dependencias |

Un truco: añade `--help` a cualquier comando para ver todas sus opciones, por ejemplo `ng generate --help`.
