# Tutorial 1: Instalando Angular CLI

¡Bienvenido a esta serie de tutoriales sobre Angular! En esta primera entrega vamos a preparar nuestro entorno de desarrollo instalando **Angular CLI**, la herramienta de línea de comandos oficial de Angular. Al terminar tendrás tu primera aplicación funcionando en el navegador.

## ¿Qué es Angular CLI?

Angular CLI (*Command Line Interface*) es una herramienta que nos permite crear, desarrollar, probar y desplegar aplicaciones Angular desde la terminal. En lugar de configurar a mano TypeScript, el empaquetador, el servidor de desarrollo y las pruebas, el CLI lo hace todo por nosotros con un solo comando.

Además, nos ayuda a generar componentes, servicios, módulos y otras piezas siguiendo las buenas prácticas y la estructura recomendada por el equipo de Angular.

## Requisitos previos

Antes de instalar Angular CLI necesitamos tener instalado **Node.js** y su gestor de paquetes **npm**.

### Instalar Node.js

1. Ve a la página oficial: [https://nodejs.org](https://nodejs.org).
2. Descarga la versión **LTS** (*Long Term Support*), que es la más estable.
3. Ejecuta el instalador y sigue los pasos. npm se instala automáticamente junto con Node.js.

Para comprobar que todo se instaló correctamente, abre una terminal y ejecuta:

```bash
node -v
npm -v
```

Deberías ver los números de versión de ambos. Si aparece un error del tipo "comando no encontrado", cierra y vuelve a abrir la terminal, o revisa que Node.js se haya añadido al `PATH` del sistema.

> **Consejo:** si trabajas con varios proyectos que requieren versiones distintas de Node, te recomiendo usar [nvm](https://github.com/nvm-sh/nvm) (o nvm-windows en Windows) para cambiar de versión fácilmente.

## Instalando Angular CLI

Con Node y npm listos, instalamos Angular CLI de forma global:

```bash
npm install -g @angular/cli
```

La opción `-g` hace que el CLI esté disponible desde cualquier carpeta del sistema.

> **Nota para macOS y Linux:** si obtienes un error de permisos, puedes anteponer `sudo` al comando, aunque lo más recomendable es configurar npm para instalar paquetes globales sin permisos de administrador, o usar nvm.

Cuando termine la instalación, verifica que todo esté correcto:

```bash
ng version
```

Verás un logo de Angular en ASCII junto con la versión del CLI, de Node y del sistema operativo.

## Creando nuestro primer proyecto

Ahora viene lo divertido. Ubícate en la carpeta donde quieras guardar tus proyectos y ejecuta:

```bash
ng new mi-primera-app
```

El CLI te hará algunas preguntas:

- **¿Qué formato de hojas de estilo quieres usar?** Puedes elegir CSS, SCSS, Sass o Less. Si no estás seguro, elige CSS.
- **¿Quieres habilitar SSR (Server-Side Rendering)?** Por ahora responde que no.

Después de eso, el CLI creará la estructura del proyecto e instalará todas las dependencias. Puede tardar un par de minutos dependiendo de tu conexión.

## Levantando el servidor de desarrollo

Entra en la carpeta del proyecto y arranca el servidor:

```bash
cd mi-primera-app
ng serve --open
```

La opción `--open` (o `-o`) abre automáticamente el navegador en `http://localhost:4200`. Si todo salió bien, verás la página de bienvenida de Angular.

Lo mejor es que el servidor tiene **recarga en caliente**: cada vez que guardes un cambio en el código, el navegador se actualizará automáticamente.

## Comandos útiles

Aquí tienes algunos comandos que usaremos a lo largo de la serie:

| Comando | Descripción |
|---|---|
| `ng new <nombre>` | Crea un nuevo proyecto |
| `ng serve` | Levanta el servidor de desarrollo |
| `ng generate component <nombre>` | Genera un componente |
| `ng build` | Compila la aplicación para producción |
| `ng test` | Ejecuta las pruebas unitarias |

## Conclusión

¡Listo! Ya tienes Angular CLI instalado y tu primera aplicación corriendo. En el próximo tutorial exploraremos la estructura de carpetas del proyecto y añadiremos una librería de componentes para empezar a construir nuestra interfaz.

Si tuviste algún problema durante la instalación, déjalo en los comentarios y te ayudo a resolverlo. ¡Nos vemos en el siguiente!
