# Magic Link Authentication and Route Controls with Supabase and Next.js

Authentication is a critical component of modern web applications, but implementing it securely can be challenging. One of the most user-friendly authentication methods is magic link authentication, which sends users a link via email that they can click to sign in without needing to remember a password.

In this comprehensive guide, we'll explore how to implement magic link authentication using Supabase and Next.js, and then we'll look at how to protect your routes based on authentication state.

## What is Magic Link Authentication?

Magic link authentication is a passwordless authentication method that works by sending users a time-limited link via email. When they click the link, they're automatically logged in. This approach combines security with user convenience—users don't need to remember passwords, and the link's expiration time ensures that compromised links can't be used indefinitely.

## Why Supabase for Authentication?

Supabase is an open-source Firebase alternative that provides a PostgreSQL database, authentication, real-time subscriptions, and storage. For authentication specifically, Supabase handles the complexity of securely managing user credentials and sessions, allowing you to focus on building your application.

Supabase supports multiple authentication methods, including email/password, OAuth providers, and magic links. It handles session management automatically and provides secure JWT tokens for API access.

## Setting Up Supabase

First, create a Supabase project at supabase.com. Once your project is created, you'll have a project URL and anon key. These are what you'll use to initialize Supabase in your Next.js application.

Install the Supabase JavaScript client:

```bash
npm install @supabase/supabase-js
```

Create a Supabase client configuration file:

```javascript
// lib/supabaseClient.js
import { createClient } from '@supabase/supabase-js'

const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL
const supabaseAnonKey = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY

export const supabase = createClient(supabaseUrl, supabaseAnonKey)
```

Add your Supabase URL and key to your environment variables:

```
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

## Implementing Magic Link Authentication

To enable magic links in Supabase, go to the Authentication settings and ensure the "Email" provider is enabled with the magic link option turned on.

Now, let's create a login component that sends magic links:

```javascript
// components/MagicLinkLogin.jsx
import { useState } from 'react'
import { supabase } from '../lib/supabaseClient'

export default function MagicLinkLogin() {
  const [email, setEmail] = useState('')
  const [loading, setLoading] = useState(false)
  const [message, setMessage] = useState('')

  const handleMagicLink = async (e) => {
    e.preventDefault()
    setLoading(true)
    setMessage('')

    const { error } = await supabase.auth.signInWithOtp({
      email: email,
    })

    if (error) {
      setMessage(`Error: ${error.message}`)
    } else {
      setMessage('Check your email for the magic link!')
    }
    setLoading(false)
  }

  return (
    <form onSubmit={handleMagicLink}>
      <input
        type="email"
        placeholder="Enter your email"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
        required
      />
      <button type="submit" disabled={loading}>
        {loading ? 'Sending...' : 'Send Magic Link'}
      </button>
      {message && <p>{message}</p>}
    </form>
  )
}
```

## Handling the Magic Link Callback

When users click the magic link in their email, they're redirected back to your application. You need to handle this redirect properly.

Create a callback page to handle the magic link:

```javascript
// pages/auth/callback.js
import { useEffect } from 'react'
import { useRouter } from 'next/router'
import { supabase } from '../../lib/supabaseClient'

export default function Callback() {
  const router = useRouter()

  useEffect(() => {
    supabase.auth.onAuthStateChange((event, session) => {
      if (event === 'SIGNED_IN') {
        router.push('/dashboard')
      }
    })
  }, [router])

  return <div>Loading...</div>
}
```

In your Supabase settings, set the redirect URL to your callback page.

## Protecting Routes with Route Controls

Now that authentication is working, you need to protect your routes so that only authenticated users can access certain pages.

Create a middleware component to check authentication state:

```javascript
// lib/protectedRoute.js
import { useEffect } from 'react'
import { useRouter } from 'next/router'
import { supabase } from './supabaseClient'

export function withProtectedRoute(Component) {
  return function ProtectedRoute(props) {
    const router = useRouter()
    const [isLoading, setIsLoading] = useState(true)

    useEffect(() => {
      supabase.auth.getSession().then(({ data: { session } }) => {
        if (!session) {
          router.push('/login')
        } else {
          setIsLoading(false)
        }
      })

      const { data: { subscription } } = supabase.auth.onAuthStateChange((event, session) => {
        if (!session) {
          router.push('/login')
        }
      })

      return () => subscription?.unsubscribe()
    }, [router])

    if (isLoading) {
      return <div>Loading...</div>
    }

    return <Component {...props} />
  }
}
```

Use this higher-order component on your protected pages:

```javascript
// pages/dashboard.js
import { withProtectedRoute } from '../lib/protectedRoute'

function Dashboard() {
  return <h1>Welcome to your dashboard!</h1>
}

export default withProtectedRoute(Dashboard)
```

Alternatively, use Next.js middleware for route protection:

```javascript
// middleware.js
import { createMiddlewareClient } from '@supabase/auth-helpers-nextjs'
import { NextResponse } from 'next/server'

export async function middleware(req) {
  const res = NextResponse.next()
  const supabase = createMiddlewareClient({ req, res })
  await supabase.auth.getSession()
  return res
}

export const config = {
  matcher: ['/dashboard/:path*', '/profile/:path*']
}
```

## Adding a Logout Function

Users should be able to sign out:

```javascript
const handleLogout = async () => {
  await supabase.auth.signOut()
  router.push('/login')
}
```

## Best Practices

Keep your Supabase credentials secure by using environment variables and never committing them to version control. Magic links should expire after a reasonable time—Supabase defaults to 24 hours, which is a good balance between security and usability.

Always validate user input and implement proper error handling. Test your authentication flow thoroughly, including edge cases like expired links and network failures.

## Conclusion

Magic link authentication with Supabase and Next.js provides a modern, user-friendly authentication experience without the overhead of managing passwords. Combined with proper route controls, you can build secure applications that respect user privacy while maintaining application security. The combination is powerful, well-documented, and battle-tested by thousands of developers.
