# Using FastImage to Detect Image Dimensions in Ruby

Applications that accept image URLs often need to know an image’s width and height before downloading or processing the entire file. You might want to validate a remote image, calculate its aspect ratio, reserve space in a layout, or reject files that are too small.

Ruby’s `fastimage` gem is designed for exactly this job. It determines an image’s dimensions by reading only the necessary portion of the file, making it much more efficient than downloading the complete image and opening it with an image-processing library.

## Installing FastImage

Add the gem to your `Gemfile`:

```ruby
gem "fastimage"
```

Then install it:

```bash
bundle install
```

Alternatively, install it directly:

```bash
gem install fastimage
```

Require it when you are not using Bundler’s automatic loading:

```ruby
require "fastimage"
```

## Reading dimensions from a URL

The main API is `FastImage.size`. Pass it an image URL and it returns an array containing the width and height:

```ruby
url = "https://example.com/images/header.jpg"

width, height = FastImage.size(url)

puts "Width: #{width}px"
puts "Height: #{height}px"
```

For a 1200-by-630 image, the result is:

```ruby
[1200, 630]
```

This works because common image formats store their dimensions in metadata near the beginning of the file. FastImage requests enough data to locate that information instead of fetching every byte.

You can also inspect the image format:

```ruby
type = FastImage.type(url)

puts type
# => :jpeg
```

FastImage supports several popular formats, including JPEG, PNG, GIF, BMP, TIFF, ICO, WebP, and SVG.

## Reading local images

FastImage is not limited to remote URLs. It can inspect files stored on disk:

```ruby
width, height = FastImage.size("public/uploads/avatar.png")

puts "#{width}x#{height}"
```

This gives your code a consistent interface whether an image is local or remote.

## Calculating an aspect ratio

Once you have the dimensions, calculating an aspect ratio is straightforward:

```ruby
width, height = FastImage.size(url)

if width && height
  aspect_ratio = width.to_f / height
  puts aspect_ratio.round(2)
end
```

Converting `width` to a float is important; it makes the intention clear and avoids integer-division surprises in older Ruby versions.

You can also classify the image:

```ruby
orientation =
  if width > height
    :landscape
  elsif height > width
    :portrait
  else
    :square
  end
```

This can be useful when selecting thumbnails or deciding how an image should appear in a responsive layout.

## Handling failures

Remote resources are unreliable. A URL may be unavailable, slow, or point to something that is not a supported image. By default, `FastImage.size` can return `nil` when it cannot determine the dimensions:

```ruby
dimensions = FastImage.size(url)

if dimensions
  width, height = dimensions
  puts "#{width}x#{height}"
else
  puts "Unable to read image dimensions"
end
```

For explicit exception handling, enable `raise_on_failure`:

```ruby
begin
  width, height = FastImage.size(
    url,
    timeout: 5,
    raise_on_failure: true
  )

  puts "#{width}x#{height}"
rescue FastImage::ImageFetchFailure => e
  warn "Could not fetch image: #{e.message}"
rescue FastImage::UnknownImageType => e
  warn "Unsupported image: #{e.message}"
end
```

Setting a timeout prevents a slow server from tying up your application indefinitely.

## Validating image dimensions

A small helper can turn dimension detection into reusable validation logic:

```ruby
def large_enough?(url, minimum_width:, minimum_height:)
  width, height = FastImage.size(url, timeout: 5)

  width >= minimum_width && height >= minimum_height
rescue TypeError
  false
end
```

Use it like this:

```ruby
large_enough?(
  "https://example.com/photo.jpg",
  minimum_width: 800,
  minimum_height: 600
)
```

When processing user-supplied URLs, remember that your server is making the request. Restrict allowed hosts or network destinations to reduce server-side request forgery risks.

FastImage is a focused tool: it does not resize, optimize, or transform images. When you only need dimensions or format information, however, it avoids the cost and complexity of a full image-processing pipeline.
