# How to build a full stack NFT marketplace - V2 (2022)

I think an NFT marketplace is a great project for learning Web3, because it pulls together smart contracts, wallet auth, decentralized storage and a modern frontend in one app.

In this tutorial we'll build a full stack NFT marketplace where users can:

- Connect an Ethereum wallet
- Mint NFTs with images and metadata
- List NFTs for sale
- Browse the NFTs that are for sale
- Buy NFTs
- See the NFTs they own and the ones they created

Our stack is Solidity, Hardhat, Polygon, Next.js, ethers.js and IPFS.

> This tutorial uses the Web3 tooling that was around in 2022. Some package APIs may be different in newer versions.

## Project architecture

The marketplace has three main layers:

1. The smart contract creates NFTs, stores listings, and handles sales.
2. IPFS stores the NFT images and metadata.
3. The Next.js app is the interface, and it talks to the blockchain.

The NFT itself uses the ERC-721 standard. Listings live in the smart contract, so we don't need a traditional backend or database.

## Create the project

Create a new Next.js app:

```bash
npx create-next-app nft-marketplace
cd nft-marketplace
```

Install the dependencies we need:

```bash
npm install ethers@5 web3modal axios
npm install ipfs-http-client
npm install --save-dev hardhat @nomiclabs/hardhat-ethers
npm install @openzeppelin/contracts
```

Set up Hardhat:

```bash
npx hardhat
```

When it asks, pick **Create a basic sample project**.

You should now have `contracts`, `scripts` and `test` directories sitting next to the Next.js app.

## Build the smart contract

Create `contracts/NFTMarketplace.sol`:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.4;

import "@openzeppelin/contracts/utils/Counters.sol";
import "@openzeppelin/contracts/token/ERC721/extensions/ERC721URIStorage.sol";
import "@openzeppelin/contracts/security/ReentrancyGuard.sol";

contract NFTMarketplace is ERC721URIStorage, ReentrancyGuard {
    using Counters for Counters.Counter;

    Counters.Counter private tokenIds;
    Counters.Counter private soldItems;

    uint256 public listingPrice = 0.025 ether;
    address payable private marketplaceOwner;

    struct MarketItem {
        uint256 tokenId;
        address payable seller;
        address payable owner;
        uint256 price;
        bool sold;
    }

    mapping(uint256 => MarketItem) private marketItems;

    event MarketItemCreated(
        uint256 indexed tokenId,
        address seller,
        address owner,
        uint256 price,
        bool sold
    );

    constructor() ERC721("Marketplace Token", "MKT") {
        marketplaceOwner = payable(msg.sender);
    }

    function createToken(
        string memory tokenURI,
        uint256 price
    ) public payable returns (uint256) {
        tokenIds.increment();
        uint256 newTokenId = tokenIds.current();

        _mint(msg.sender, newTokenId);
        _setTokenURI(newTokenId, tokenURI);
        createMarketItem(newTokenId, price);

        return newTokenId;
    }

    function createMarketItem(
        uint256 tokenId,
        uint256 price
    ) private {
        require(price > 0, "Price must be greater than zero");
        require(
            msg.value == listingPrice,
            "Submit the required listing price"
        );

        marketItems[tokenId] = MarketItem(
            tokenId,
            payable(msg.sender),
            payable(address(this)),
            price,
            false
        );

        _transfer(msg.sender, address(this), tokenId);

        emit MarketItemCreated(
            tokenId,
            msg.sender,
            address(this),
            price,
            false
        );
    }
}
```

When an NFT gets listed, ownership moves to the marketplace contract. The contract holds the NFT in escrow until someone buys it.

Next, we add the function that handles a purchase:

```solidity
function createMarketSale(uint256 tokenId) public payable nonReentrant {
    MarketItem storage item = marketItems[tokenId];

    require(msg.value == item.price, "Submit the asking price");
    require(!item.sold, "Item has already been sold");

    item.seller.transfer(msg.value);
    transferFrom(address(this), msg.sender, tokenId);

    item.owner = payable(msg.sender);
    item.sold = true;
    soldItems.increment();

    marketplaceOwner.transfer(listingPrice);
}
```

The `nonReentrant` modifier protects the transaction from reentrancy attacks while the funds and the ownership are being transferred.

Then we'll add a function that loads the NFTs that haven't sold yet:

```solidity
function fetchMarketItems() public view returns (MarketItem[] memory) {
    uint256 totalItems = tokenIds.current();
    uint256 unsoldCount = totalItems - soldItems.current();
    uint256 index = 0;

    MarketItem[] memory items = new MarketItem[](unsoldCount);

    for (uint256 i = 1; i <= totalItems; i++) {
        if (marketItems[i].owner == address(this)) {
            items[index] = marketItems[i];
            index++;
        }
    }

    return items;
}
```

You can write similar view functions for the NFTs a user owns and the ones they created:

```solidity
function fetchMyNFTs() public view returns (MarketItem[] memory) {
    uint256 totalItems = tokenIds.current();
    uint256 itemCount = 0;
    uint256 index = 0;

    for (uint256 i = 1; i <= totalItems; i++) {
        if (marketItems[i].owner == msg.sender) {
            itemCount++;
        }
    }

    MarketItem[] memory items = new MarketItem[](itemCount);

    for (uint256 i = 1; i <= totalItems; i++) {
        if (marketItems[i].owner == msg.sender) {
            items[index] = marketItems[i];
            index++;
        }
    }

    return items;
}
```

## Configure Hardhat

Update `hardhat.config.js`:

```javascript
require("@nomiclabs/hardhat-ethers");

module.exports = {
  solidity: "0.8.4",
  networks: {
    hardhat: {
      chainId: 1337,
    },
  },
};
```

Compile the contract:

```bash
npx hardhat compile
```

Create `scripts/deploy.js`:

```javascript
async function main() {
  const Marketplace = await ethers.getContractFactory("NFTMarketplace");
  const marketplace = await Marketplace.deploy();

  await marketplace.deployed();

  console.log("Marketplace deployed to:", marketplace.address);
}

main()
  .then(() => process.exit(0))
  .catch((error) => {
    console.error(error);
    process.exit(1);
  });
```

Start a local blockchain:

```bash
npx hardhat node
```

In another terminal, deploy the contract:

```bash
npx hardhat run scripts/deploy.js --network localhost
```

Copy the address of the deployed contract. We'll need it shortly in the frontend.

## Configure the frontend

Create `config.js` in the root of the project:

```javascript
export const marketplaceAddress =
  "YOUR_DEPLOYED_CONTRACT_ADDRESS";
```

Hardhat puts the contract ABI in the `artifacts` directory. Import the artifact anywhere the frontend needs to create a contract instance.

For a read-only connection we can use a JSON-RPC provider:

```javascript
import { ethers } from "ethers";
import NFTMarketplace from "./artifacts/contracts/NFTMarketplace.sol/NFTMarketplace.json";
import { marketplaceAddress } from "./config";

const provider = new ethers.providers.JsonRpcProvider(
  "http://127.0.0.1:8545"
);

const contract = new ethers.Contract(
  marketplaceAddress,
  NFTMarketplace.abi,
  provider
);
```

Sending a transaction needs a wallet signer, so let's write a small helper:

```javascript
import Web3Modal from "web3modal";

async function getSignedContract() {
  const web3Modal = new Web3Modal();
  const connection = await web3Modal.connect();
  const provider = new ethers.providers.Web3Provider(connection);
  const signer = provider.getSigner();

  return new ethers.Contract(
    marketplaceAddress,
    NFTMarketplace.abi,
    signer
  );
}
```

Web3Modal opens the screen where the user picks a wallet, and ethers.js wraps that wallet as a signer.

## Upload NFT assets to IPFS

An NFT's `tokenURI` usually points to a JSON document with its name, description and image URL. We can store both the image and the metadata on IPFS.

Set up an IPFS client with whichever IPFS pinning service you like:

```javascript
import { create as createIPFSClient } from "ipfs-http-client";

const client = createIPFSClient({
  url: "YOUR_IPFS_API_ENDPOINT",
  headers: {
    authorization: "YOUR_AUTHORIZATION_HEADER",
  },
});
```

In production, don't ever put a private IPFS API secret in browser code. Put uploads behind a server-side API route, or use a provider that supports safely scoped uploads from the client.

Upload the image the user picked:

```javascript
async function uploadImage(event) {
  const file = event.target.files[0];
  if (!file) return;

  const result = await client.add(file);
  const imageUrl = `https://ipfs.io/ipfs/${result.path}`;

  setFileUrl(imageUrl);
}
```

Then upload the metadata:

```javascript
async function createMetadata(name, description, image) {
  const data = JSON.stringify({
    name,
    description,
    image,
  });

  const result = await client.add(data);
  return `https://ipfs.io/ipfs/${result.path}`;
}
```

## Mint and list an NFT

The mint form should ask for a name, a description, a price and an image. Once everything is uploaded, call `createToken`:

```javascript
async function createNFT() {
  const metadataUrl = await createMetadata(
    formInput.name,
    formInput.description,
    fileUrl
  );

  const contract = await getSignedContract();
  const price = ethers.utils.parseUnits(formInput.price, "ether");
  const listingPrice = await contract.listingPrice();

  const transaction = await contract.createToken(
    metadataUrl,
    price,
    {
      value: listingPrice,
    }
  );

  await transaction.wait();
}
```

This one contract call is really two things on the blockchain: it mints the token and it puts it into escrow in the marketplace.

I'd definitely validate the form before you submit it. A missing image or a bad price should never make it as far as the wallet's confirm step.

## Display marketplace NFTs

To show the marketplace, load the unsold items and fetch each token's metadata:

```javascript
async function loadNFTs() {
  const data = await contract.fetchMarketItems();

  const items = await Promise.all(
    data.map(async (item) => {
      const tokenUri = await contract.tokenURI(item.tokenId);
      const metadata = await axios.get(tokenUri);

      return {
        tokenId: item.tokenId.toNumber(),
        seller: item.seller,
        owner: item.owner,
        price: ethers.utils.formatUnits(
          item.price.toString(),
          "ether"
        ),
        image: metadata.data.image,
        name: metadata.data.name,
        description: metadata.data.description,
      };
    })
  );

  setNfts(items);
}
```

Then render what comes back with plain React components:

```jsx
{nfts.map((nft) => (
  <article key={nft.tokenId}>
    <img src={nft.image} alt={nft.name} />
    <h2>{nft.name}</h2>
    <p>{nft.description}</p>
    <strong>{nft.price} ETH</strong>
    <button onClick={() => buyNFT(nft)}>Buy</button>
  </article>
))}
```

## Buy an NFT

Buying calls `createMarketSale` and sends the exact asking price:

```javascript
async function buyNFT(nft) {
  const contract = await getSignedContract();
  const price = ethers.utils.parseUnits(nft.price, "ether");

  const transaction = await contract.createMarketSale(
    nft.tokenId,
    {
      value: price,
    }
  );

  await transaction.wait();
  await loadNFTs();
}
```

Once the transaction is confirmed, the seller gets paid, the buyer gets the NFT, and the item drops out of the listings.

## Deploy to Polygon

Local development is great for testing quickly, but a public marketplace needs a shared network. Polygon has low transaction fees and it works with Ethereum tooling.

Add Polygon's test network to your Hardhat config with an RPC provider and a wallet to deploy from:

```javascript
require("dotenv").config();

module.exports = {
  solidity: "0.8.4",
  networks: {
    polygonTestnet: {
      url: process.env.POLYGON_RPC_URL,
      accounts: [process.env.PRIVATE_KEY],
    },
  },
};
```

Keep the credentials in `.env`:

```text
POLYGON_RPC_URL=YOUR_RPC_URL
PRIVATE_KEY=YOUR_PRIVATE_KEY
```

Don't ever commit this file. Add it to `.gitignore`, fund the deploy wallet with test tokens, and deploy:

```bash
npx hardhat run scripts/deploy.js --network polygonTestnet
```

Swap our local contract address in `config.js` for the new one. Your wallet and your frontend also have to be on the same network.

## Production considerations

This marketplace is a good base for learning, but contracts in production need more work. Before it handles anything with real value, I'd want to:

- Write tests for minting, buying, permissions and failed transactions.
- Pick a clear model for fees and royalties.
- Emit events for every important change in state.
- Get rid of loops that grow without limit as the collection grows.
- Think about indexing events with a service like The Graph.
- Pin IPFS content with more than one reliable provider.
- Handle rejected transactions and wrong networks in the UI.
- Get an independent security audit of the smart contract.

Upgradable contracts can be useful, but they come with governance and security tradeoffs. An immutable contract is often easier for users to reason about, and that's what I'd lean toward.

## Conclusion

You now have the base of a full stack NFT marketplace. Solidity handles ownership and sales, IPFS stores the decentralized metadata, ethers.js connects the browser to the blockchain, and Next.js gives users something to click on.

From here you could add auctions, creator royalties, collection pages, search, activity feeds and better wallet support. What I care about more is that you've seen how the big pieces of a Web3 app fit together, all the way from uploading an image to moving an asset on chain.
