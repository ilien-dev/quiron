# How to Build a Full Stack NFT Marketplace - V2 (2022)

NFT marketplaces are excellent projects for learning Web3 because they combine smart contracts, wallet authentication, decentralized storage, and a modern frontend.

In this tutorial, we’ll build a full-stack NFT marketplace where users can:

- Connect an Ethereum wallet
- Mint NFTs with images and metadata
- List NFTs for sale
- Browse available NFTs
- Purchase NFTs
- View owned and created assets

Our stack will include Solidity, Hardhat, Polygon, Next.js, ethers.js, and IPFS.

> This tutorial uses the Web3 tooling available in 2022. Some package APIs may differ in newer versions.

## Project architecture

The marketplace has three main layers:

1. **Smart contract:** Creates NFTs, stores listings, and processes sales.
2. **IPFS:** Stores NFT images and metadata.
3. **Next.js application:** Provides the interface and communicates with the blockchain.

The NFT itself uses the ERC-721 standard. Marketplace listings live in the smart contract, so users do not need a traditional backend or database.

## Build the smart contract

Create `contracts/NFTMarketplace.sol`:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.4;

import "@openzeppelin/contracts/utils/Counters.sol";
import "@openzeppelin/contracts/token/ERC721/extensions/ERC721URIStorage.sol";
import "@openzeppelin/contracts/security/ReentrancyGuard.sol";

contract NFTMarketplace is ERC721URIStorage, ReentrancyGuard {
    using Counters for Counters.Counter;

    Counters.Counter private tokenIds;
    Counters.Counter private soldItems;

    uint256 public listingPrice = 0.025 ether;
    address payable private marketplaceOwner;

    struct MarketItem {
        uint256 tokenId;
        address payable seller;
        address payable owner;
        uint256 price;
        bool sold;
    }

    mapping(uint256 => MarketItem) private marketItems;

    event MarketItemCreated(
        uint256 indexed tokenId,
        address seller,
        address owner,
        uint256 price,
        bool sold
    );

    constructor() ERC721("Marketplace Token", "MKT") {
        marketplaceOwner = payable(msg.sender);
    }

    function createToken(
        string memory tokenURI,
        uint256 price
    ) public payable returns (uint256) {
        tokenIds.increment();
        uint256 newTokenId = tokenIds.current();

        _mint(msg.sender, newTokenId);
        _setTokenURI(newTokenId, tokenURI);
        createMarketItem(newTokenId, price);

        return newTokenId;
    }

    function createMarketItem(
        uint256 tokenId,
        uint256 price
    ) private {
        require(price > 0, "Price must be greater than zero");
        require(
            msg.value == listingPrice,
            "Submit the required listing price"
        );

        marketItems[tokenId] = MarketItem(
            tokenId,
            payable(msg.sender),
            payable(address(this)),
            price,
            false
        );

        _transfer(msg.sender, address(this), tokenId);

        emit MarketItemCreated(
            tokenId,
            msg.sender,
            address(this),
            price,
            false
        );
    }
}
```

When an NFT is listed, ownership is transferred to the marketplace contract. The contract holds the NFT in escrow until someone buys it.

Next, add the purchase function:

```solidity
function createMarketSale(uint256 tokenId) public payable nonReentrant {
    MarketItem storage item = marketItems[tokenId];

    require(msg.value == item.price, "Submit the asking price");
    require(!item.sold, "Item has already been sold");

    item.seller.transfer(msg.value);
    transferFrom(address(this), msg.sender, tokenId);

    item.owner = payable(msg.sender);
    item.sold = true;
    soldItems.increment();

    marketplaceOwner.transfer(listingPrice);
}
```

The `nonReentrant` modifier protects the transaction from reentrancy attacks while funds and ownership are transferred.

Add a function for loading unsold NFTs:

```solidity
function fetchMarketItems() public view returns (MarketItem[] memory) {
    uint256 totalItems = tokenIds.current();
    uint256 unsoldCount = totalItems - soldItems.current();
    uint256 index = 0;

    MarketItem[] memory items = new MarketItem[](unsoldCount);

    for (uint256 i = 1; i <= totalItems; i++) {
        if (marketItems[i].owner == address(this)) {
            items[index] = marketItems[i];
            index++;
        }
    }

    return items;
}
```

You can create similar view functions for owned and created NFTs:

```solidity
function fetchMyNFTs() public view returns (MarketItem[] memory) {
    uint256 totalItems = tokenIds.current();
    uint256 itemCount = 0;
    uint256 index = 0;

    for (uint256 i = 1; i <= totalItems; i++) {
        if (marketItems[i].owner == msg.sender) {
            itemCount++;
        }
    }

    MarketItem[] memory items = new MarketItem[](itemCount);

    for (uint256 i = 1; i <= totalItems; i++) {
        if (marketItems[i].owner == msg.sender) {
            items[index] = marketItems[i];
            index++;
        }
    }

    return items;
}
```

## Configure the frontend

Create `config.js` in the project root:

```javascript
export const marketplaceAddress =
  "YOUR_DEPLOYED_CONTRACT_ADDRESS";
```

Hardhat generates the contract ABI inside the `artifacts` directory. Import the artifact wherever the frontend needs to create a contract instance.

A read-only connection can use a JSON-RPC provider:

```javascript
import { ethers } from "ethers";
import NFTMarketplace from "./artifacts/contracts/NFTMarketplace.sol/NFTMarketplace.json";
import { marketplaceAddress } from "./config";

const provider = new ethers.providers.JsonRpcProvider(
  "http://127.0.0.1:8545"
);

const contract = new ethers.Contract(
  marketplaceAddress,
  NFTMarketplace.abi,
  provider
);
```

Transactions require a wallet signer. Create a small helper:

```javascript
import Web3Modal from "web3modal";

async function getSignedContract() {
  const web3Modal = new Web3Modal();
  const connection = await web3Modal.connect();
  const provider = new ethers.providers.Web3Provider(connection);
  const signer = provider.getSigner();

  return new ethers.Contract(
    marketplaceAddress,
    NFTMarketplace.abi,
    signer
  );
}
```

Web3Modal opens the wallet-selection interface, while ethers.js wraps the selected wallet as a signer.

## Upload NFT assets to IPFS

An NFT’s `tokenURI` normally points to a JSON document containing its name, description, and image URL. Both the image and metadata can be stored on IPFS.

Configure an IPFS client using your preferred IPFS pinning service:

```javascript
import { create as createIPFSClient } from "ipfs-http-client";

const client = createIPFSClient({
  url: "YOUR_IPFS_API_ENDPOINT",
  headers: {
    authorization: "YOUR_AUTHORIZATION_HEADER",
  },
});
```

In production, never expose a private IPFS API secret in browser code. Place uploads behind a server-side API route or use a provider that supports safely scoped client uploads.

Upload the selected image:

```javascript
async function uploadImage(event) {
  const file = event.target.files[0];
  if (!file) return;

  const result = await client.add(file);
  const imageUrl = `https://ipfs.io/ipfs/${result.path}`;

  setFileUrl(imageUrl);
}
```

Next, upload the metadata:

```javascript
async function createMetadata(name, description, image) {
  const data = JSON.stringify({
    name,
    description,
    image,
  });

  const result = await client.add(data);
  return `https://ipfs.io/ipfs/${result.path}`;
}
```

## Mint and list an NFT

The minting form should collect a name, description, price, and image. Once everything is uploaded, call `createToken`:

```javascript
async function createNFT() {
  const metadataUrl = await createMetadata(
    formInput.name,
    formInput.description,
    fileUrl
  );

  const contract = await getSignedContract();
  const price = ethers.utils.parseUnits(formInput.price, "ether");
  const listingPrice = await contract.listingPrice();

  const transaction = await contract.createToken(
    metadataUrl,
    price,
    {
      value: listingPrice,
    }
  );

  await transaction.wait();
}
```

There are two blockchain operations hidden inside this contract call: minting the token and placing it into marketplace escrow.

Validate the form before submitting it. A missing image or invalid price should never reach the wallet confirmation stage.

## Display marketplace NFTs

To render the marketplace, load the unsold items and resolve each token’s metadata:

```javascript
async function loadNFTs() {
  const data = await contract.fetchMarketItems();

  const items = await Promise.all(
    data.map(async (item) => {
      const tokenUri = await contract.tokenURI(item.tokenId);
      const metadata = await axios.get(tokenUri);

      return {
        tokenId: item.tokenId.toNumber(),
        seller: item.seller,
        owner: item.owner,
        price: ethers.utils.formatUnits(
          item.price.toString(),
          "ether"
        ),
        image: metadata.data.image,
        name: metadata.data.name,
        description: metadata.data.description,
      };
    })
  );

  setNfts(items);
}
```

Render the returned data using regular React components:

```jsx
{nfts.map((nft) => (
  <article key={nft.tokenId}>
    <img src={nft.image} alt={nft.name} />
    <h2>{nft.name}</h2>
    <p>{nft.description}</p>
    <strong>{nft.price} ETH</strong>
    <button onClick={() => buyNFT(nft)}>Buy</button>
  </article>
))}
```

## Purchase an NFT

Purchasing calls `createMarketSale` and sends the exact asking price:

```javascript
async function buyNFT(nft) {
  const contract = await getSignedContract();
  const price = ethers.utils.parseUnits(nft.price, "ether");

  const transaction = await contract.createMarketSale(
    nft.tokenId,
    {
      value: price,
    }
  );

  await transaction.wait();
  await loadNFTs();
}
```

After confirmation, the seller receives payment, the buyer receives the NFT, and the item disappears from the available listings.

## Deploy to Polygon

Local development is ideal for fast testing, but a public marketplace needs a shared network. Polygon offers low transaction fees and is compatible with Ethereum tooling.

Add Polygon’s test network to your Hardhat configuration using an RPC provider and a deployment wallet:

```javascript
require("dotenv").config();

module.exports = {
  solidity: "0.8.4",
  networks: {
    polygonTestnet: {
      url: process.env.POLYGON_RPC_URL,
      accounts: [process.env.PRIVATE_KEY],
    },
  },
};
```

Store credentials in `.env`:

```text
POLYGON_RPC_URL=YOUR_RPC_URL
PRIVATE_KEY=YOUR_PRIVATE_KEY
```

Never commit this file. Add it to `.gitignore`, fund the deployment wallet with test tokens, and deploy:

```bash
npx hardhat run scripts/deploy.js --network polygonTestnet
```

Replace the local contract address in `config.js` with the new address. Your wallet and frontend must also use the same network.

## Production considerations

This marketplace is a solid educational foundation, but production contracts require additional work.

Before handling assets with real value:

- Write tests for minting, buying, permissions, and failed transactions.
- Use a well-defined fee and royalty model.
- Add events for every important state transition.
- Avoid unbounded loops as the collection grows.
- Consider indexing events with a service such as The Graph.
- Pin IPFS content through multiple reliable providers.
- Handle rejected transactions and network mismatches in the UI.
- Obtain an independent smart-contract security audit.

Upgradable contracts may be useful, but they introduce governance and security tradeoffs. Immutability is often easier for users to reason about.

## Conclusion

You now have the foundation of a full-stack NFT marketplace: Solidity manages ownership and sales, IPFS stores decentralized metadata, ethers.js connects the browser to the blockchain, and Next.js provides the user experience.

From here, you can add auctions, creator royalties, collection pages, search, activity feeds, and improved wallet support. More importantly, you now understand how the major pieces of a Web3 application work together—from uploading an image to transferring an on-chain asset.
