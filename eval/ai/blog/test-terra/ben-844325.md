# Using FastImage to detect image dimensions in Ruby

Sometimes you need an image’s dimensions without actually displaying or processing it. Maybe you’re building a photo gallery, validating an upload, or adding `width` and `height` attributes to prevent a page from jumping as images load.

For remote images, downloading the entire file just to learn its dimensions can be wasteful. The [FastImage gem](https://github.com/sdsykes/fastimage) offers a simpler approach: it reads enough of an image to determine its size or type.

## Install FastImage

Add the gem to your `Gemfile`:

```ruby
gem "fastimage"
```

Then install it:

```bash
bundle install
```

Or, if you’re working outside a Bundler project:

```bash
gem install fastimage
```

## Get an image’s dimensions

Require the gem and pass a URL to `FastImage.size`:

```ruby
require "fastimage"

dimensions = FastImage.size("https://example.com/photo.jpg")

if dimensions
  width, height = dimensions
  puts "Width: #{width}px"
  puts "Height: #{height}px"
else
  puts "Could not determine the image dimensions"
end
```

When successful, `FastImage.size` returns a two-element array: **width first, then height**. It returns `nil` if it can’t determine the size, so check the result before using it.

The URL above is a placeholder; replace it with an image you can access.

## Read local files and uploads

FastImage also accepts a local path:

```ruby
dimensions = FastImage.size("public/images/portrait.png")
```

Or an IO object, which can be useful when working with an uploaded file:

```ruby
File.open("public/images/portrait.png", "rb") do |file|
  width, height = FastImage.size(file)
  puts "#{width} x #{height}" if width && height
end
```

For example, you could use the dimensions to check that an uploaded image meets a minimum size:

```ruby
def large_enough?(file)
  dimensions = FastImage.size(file)
  return false unless dimensions

  width, height = dimensions
  width >= 800 && height >= 600
end
```

If another part of your application needs to read the same IO object afterward, manage its position appropriately—for example, by rewinding it if the object supports that operation.

## Identify the image type

You can also ask FastImage for the detected format:

```ruby
type = FastImage.type("public/images/portrait.png")

puts type # => :png
```

This can be useful when a filename has a misleading extension. FastImage supports several formats, including JPEG, PNG, GIF, WebP, and SVG. See the [project README](https://github.com/sdsykes/fastimage) for the full list and usage options.

## Handle slow or unavailable URLs

Remote servers can be slow, return errors, or serve data that isn’t a recognizable image. You can set a timeout and request an exception instead of receiving `nil`:

```ruby
begin
  width, height = FastImage.size(
    "https://example.com/photo.jpg",
    timeout: 3,
    raise_on_failure: true
  )

  puts "#{width} x #{height}"
rescue FastImage::ImageFetchFailure, FastImage::SizeNotFound => e
  warn "Could not inspect the image: #{e.message}"
end
```

Choose a timeout that suits your application. If you’re inspecting many remote images, consider doing that work in a background job and saving the results so you don’t make a network request every time you render a page.

## Be careful with user-supplied locations

FastImage can open local files as well as remote URLs, and it follows redirects. Don’t pass arbitrary user input directly to it. Restrict acceptable locations and account for redirects and network addresses when designing your application’s protections. For uploads, inspect a file your application has already received instead of accepting an unrestricted path.

FastImage is handy when you need metadata without bringing in a full image-processing library. Give it a path, URL, or IO object, handle the possibility that detection fails, and you can use the dimensions wherever your application needs them.
