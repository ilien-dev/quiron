# How to Build a Full Stack NFT Marketplace - V2 (2022)

> View the video version of this tutorial [here](https://www.youtube.com/watch?v=GKJBEEXUha0). The code for the project is located [here](https://github.com/dabit3/polygon-ethereum-nextjs-marketplace/), and if you're looking for V1, it's [here](https://gist.github.com/dabit3/ce61bb1593c9aeae31f2a31bcad7f5da).

This is the second version of my NFT marketplace tutorial. It builds on [The Complete Guide to Full Stack Ethereum Development](https://dev.to/dabit3/the-complete-guide-to-full-stack-ethereum-development-3j13), so if you haven't read that one, it might be a good place to start.

This time the app runs on Polygon. Layer 2 and scaling solutions like Polygon, Arbitrum, and Optimism are gaining traction really fast, but there's still very little content out there on how to actually build on them. So I'm planning a series, and this is the first part.

Polygon (formerly Matic, a name still used for the token and the network) is about [10x faster and more than 10x cheaper](https://twitter.com/ChainLinkGod/status/1405688790241316864) than Ethereum. The best part is that if you already know how to build on Ethereum, there's almost nothing new to learn. The same tools and the same code work here, and your skills transfer.

The app we're building is called Metaverse Marketplace. Users can mint an NFT with an image and metadata, list it for sale, browse what's for sale, and buy it. The stack:

- Next.js and Tailwind for the frontend
- Solidity and Hardhat for the smart contract
- Ethers.js to talk to the blockchain from the browser
- IPFS for file storage
- Polygon for the network

### Prerequisites

You'll need Node.js 16.14.0 or later. I recommend installing it with nvm or fnm. You'll also need the MetaMask wallet extension in your browser.

### Setting up the project

Create a new Next.js app and install the dependencies:

```bash
npx create-next-app nft-marketplace
cd nft-marketplace

npm install ethers@5 web3modal axios
npm install ipfs-http-client
npm install --save-dev hardhat @nomiclabs/hardhat-ethers
npm install @openzeppelin/contracts
```

Then initialize Hardhat:

```bash
npx hardhat
```

Choose **Create a basic sample project** when prompted. If it errors on `README.md`, delete that file and run the command again.

### The smart contract

The whole app uses a single contract, `NFTMarketplace.sol`. The NFT itself is an ERC721 token from OpenZeppelin, so we don't have to write that part ourselves. There's no traditional backend or database here: the listings live in the contract.

Every listing costs a fee of 0.025 ether, which goes to the owner of the marketplace. When an NFT is listed, ownership moves to the marketplace contract, which holds it until somebody buys it.

Create `contracts/NFTMarketplace.sol`:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.4;

import "@openzeppelin/contracts/utils/Counters.sol";
import "@openzeppelin/contracts/token/ERC721/extensions/ERC721URIStorage.sol";
import "@openzeppelin/contracts/security/ReentrancyGuard.sol";

contract NFTMarketplace is ERC721URIStorage, ReentrancyGuard {
    using Counters for Counters.Counter;

    Counters.Counter private tokenIds;
    Counters.Counter private soldItems;

    uint256 public listingPrice = 0.025 ether;
    address payable private marketplaceOwner;

    struct MarketItem {
        uint256 tokenId;
        address payable seller;
        address payable owner;
        uint256 price;
        bool sold;
    }

    mapping(uint256 => MarketItem) private marketItems;

    event MarketItemCreated(
        uint256 indexed tokenId,
        address seller,
        address owner,
        uint256 price,
        bool sold
    );

    constructor() ERC721("Metaverse Tokens", "METT") {
        marketplaceOwner = payable(msg.sender);
    }

    function createToken(
        string memory tokenURI,
        uint256 price
    ) public payable returns (uint256) {
        tokenIds.increment();
        uint256 newTokenId = tokenIds.current();

        _mint(msg.sender, newTokenId);
        _setTokenURI(newTokenId, tokenURI);
        createMarketItem(newTokenId, price);

        return newTokenId;
    }

    function createMarketItem(
        uint256 tokenId,
        uint256 price
    ) private {
        require(price > 0, "Price must be greater than zero");
        require(
            msg.value == listingPrice,
            "Submit the required listing price"
        );

        marketItems[tokenId] = MarketItem(
            tokenId,
            payable(msg.sender),
            payable(address(this)),
            price,
            false
        );

        _transfer(msg.sender, address(this), tokenId);

        emit MarketItemCreated(
            tokenId,
            msg.sender,
            address(this),
            price,
            false
        );
    }
}
```

Next, add the function that handles a sale. The `nonReentrant` modifier protects it from reentrancy attacks while the funds and the token change hands:

```solidity
function createMarketSale(uint256 tokenId) public payable nonReentrant {
    MarketItem storage item = marketItems[tokenId];

    require(msg.value == item.price, "Submit the asking price");
    require(!item.sold, "Item has already been sold");

    item.seller.transfer(msg.value);
    transferFrom(address(this), msg.sender, tokenId);

    item.owner = payable(msg.sender);
    item.sold = true;
    soldItems.increment();

    marketplaceOwner.transfer(listingPrice);
}
```

And one to return the items that haven't sold yet:

```solidity
function fetchMarketItems() public view returns (MarketItem[] memory) {
    uint256 totalItems = tokenIds.current();
    uint256 unsoldCount = totalItems - soldItems.current();
    uint256 index = 0;

    MarketItem[] memory items = new MarketItem[](unsoldCount);

    for (uint256 i = 1; i <= totalItems; i++) {
        if (marketItems[i].owner == address(this)) {
            items[index] = marketItems[i];
            index++;
        }
    }

    return items;
}
```

You can write similar view functions for the NFTs a user owns and the ones they've created.

### Testing locally

Update `hardhat.config.js`. We're using chain ID 1337 for the local network, Solidity 0.8.4, and the optimizer set to 200 runs:

```javascript
require("@nomiclabs/hardhat-ethers");

module.exports = {
  solidity: {
    version: "0.8.4",
    settings: {
      optimizer: {
        enabled: true,
        runs: 200,
      },
    },
  },
  networks: {
    hardhat: {
      chainId: 1337,
    },
  },
};
```

Then create `scripts/deploy.js`:

```javascript
async function main() {
  const Marketplace = await ethers.getContractFactory("NFTMarketplace");
  const marketplace = await Marketplace.deploy();

  await marketplace.deployed();

  console.log("Marketplace deployed to:", marketplace.address);
}

main()
  .then(() => process.exit(0))
  .catch((error) => {
    console.error(error);
    process.exit(1);
  });
```

Start a local node:

```bash
npx hardhat node
```

This gives you 20 test accounts with 10000 ETH each. Import two or three of them into MetaMask using their private keys, so you can buy and sell between them.

In another terminal, deploy the contract:

```bash
npx hardhat run scripts/deploy.js --network localhost
```

Copy the address it prints into a `config.js` file at the root of the project:

```javascript
export const marketplaceAddress =
  "YOUR_DEPLOYED_CONTRACT_ADDRESS";
```

### The frontend

For reading data, a plain JSON-RPC provider is enough. Hardhat puts the contract ABI in the `artifacts` directory:

```javascript
import { ethers } from "ethers";
import NFTMarketplace from "./artifacts/contracts/NFTMarketplace.sol/NFTMarketplace.json";
import { marketplaceAddress } from "./config";

const provider = new ethers.providers.JsonRpcProvider(
  "http://127.0.0.1:8545"
);

const contract = new ethers.Contract(
  marketplaceAddress,
  NFTMarketplace.abi,
  provider
);
```

Anything that sends a transaction needs a signer from the user's wallet. Web3Modal opens the wallet picker, and ethers wraps whatever wallet the user picked:

```javascript
import Web3Modal from "web3modal";

async function getSignedContract() {
  const web3Modal = new Web3Modal();
  const connection = await web3Modal.connect();
  const provider = new ethers.providers.Web3Provider(connection);
  const signer = provider.getSigner();

  return new ethers.Contract(
    marketplaceAddress,
    NFTMarketplace.abi,
    signer
  );
}
```

An NFT's `tokenURI` points to a JSON file with its name, description, and image, and we put both the image and that JSON on IPFS. Don't expose a private IPFS API secret in browser code in production: put the uploads behind an API route, or use a provider that supports scoped client uploads.

```javascript
import { create as createIPFSClient } from "ipfs-http-client";

const client = createIPFSClient({
  url: "YOUR_IPFS_API_ENDPOINT",
  headers: {
    authorization: "YOUR_AUTHORIZATION_HEADER",
  },
});

async function uploadImage(event) {
  const file = event.target.files[0];
  if (!file) return;

  const result = await client.add(file);
  const imageUrl = `https://ipfs.io/ipfs/${result.path}`;

  setFileUrl(imageUrl);
}

async function createMetadata(name, description, image) {
  const data = JSON.stringify({
    name,
    description,
    image,
  });

  const result = await client.add(data);
  return `https://ipfs.io/ipfs/${result.path}`;
}
```

Once the image and metadata are on IPFS, one call to `createToken` mints the NFT and puts it up for sale. The listing fee gets paid in the same call:

```javascript
async function createNFT() {
  const metadataUrl = await createMetadata(
    formInput.name,
    formInput.description,
    fileUrl
  );

  const contract = await getSignedContract();
  const price = ethers.utils.parseUnits(formInput.price, "ether");
  const listingPrice = await contract.listingPrice();

  const transaction = await contract.createToken(
    metadataUrl,
    price,
    {
      value: listingPrice,
    }
  );

  await transaction.wait();
}
```

To show the marketplace, fetch the unsold items. Then load each token's metadata from IPFS:

```javascript
async function loadNFTs() {
  const data = await contract.fetchMarketItems();

  const items = await Promise.all(
    data.map(async (item) => {
      const tokenUri = await contract.tokenURI(item.tokenId);
      const metadata = await axios.get(tokenUri);

      return {
        tokenId: item.tokenId.toNumber(),
        seller: item.seller,
        owner: item.owner,
        price: ethers.utils.formatUnits(
          item.price.toString(),
          "ether"
        ),
        image: metadata.data.image,
        name: metadata.data.name,
        description: metadata.data.description,
      };
    })
  );

  setNfts(items);
}
```

Buying simply calls `createMarketSale` with the exact asking price. After the transaction goes through, the seller has been paid, the buyer owns the NFT, and it's gone from the listings:

```javascript
async function buyNFT(nft) {
  const contract = await getSignedContract();
  const price = ethers.utils.parseUnits(nft.price, "ether");

  const transaction = await contract.createMarketSale(
    nft.tokenId,
    {
      value: price,
    }
  );

  await transaction.wait();
  await loadNFTs();
}
```

### Deploying to Polygon

Now for the Mumbai testnet. First add it to MetaMask:

- RPC URL: https://rpc-mumbai.maticvigil.com
- Chain ID: 80001
- Currency symbol: Matic

Then get some test Matic from the [faucet](https://faucet.matic.network/).

Add the network to `hardhat.config.js`, alongside the local one:

```javascript
networks: {
  hardhat: {
    chainId: 1337,
  },
  mumbai: {
    url: "https://rpc-mumbai.maticvigil.com",
    accounts: [process.env.PRIVATE_KEY],
  },
},
```

**Never commit or share your private key.** Use a test wallet that doesn't hold anything real, and keep the key out of source control.

The public RPC can get congested or rate-limit you. If that happens, use one of these RPC providers instead:

- Infura
- Alchemy
- QuickNode
- Figment DataHub
- Chainstack
- Ankr
- MaticVigil

Deploy:

```bash
npx hardhat run scripts/deploy.js --network mumbai
```

One bug I ran into here: Hardhat sometimes printed the wrong contract address. If your app can't find the contract, look up your deployment on [Mumbai Polygonscan](https://mumbai.polygonscan.com/) and use the address from there. Put that address in `config.js`, and make sure MetaMask is on Mumbai too.
