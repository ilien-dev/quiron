## Summary

This PR updates the ArcGIS Earth Automation API repository to support **ArcGIS Earth v1.10**.

## Changes

- Updated the API documentation and references to reflect the v1.10 release.
- Refreshed the sample code and projects so they build and run against the v1.10 automation interfaces.
- Revised version numbers, dependency references, and any release notes affected by the upgrade.
- Cleaned up outdated content that no longer applies to the new version.

## Testing

- Built the updated samples against ArcGIS Earth v1.10.
- Verified that the automation API calls (camera, graphics, and layer operations) behave as expected.
- Confirmed the documentation links and examples are accurate.

## Notes

No breaking changes are intended for existing users. Anyone still on an earlier ArcGIS Earth version should continue using the previous release of this repository.

Please review the updated samples and documentation for accuracy, and let me know if any additional v1.10 features should be covered.
