Stock Movements now displays and exports each movement’s `created_at` timestamp, making it easier to see when a record was created and to trace inventory activity.

Previously, users reviewing movements had to work without the creation timestamp in the displayed and exported data. This made it harder to investigate entries, compare records, and follow up on questions about when a movement was entered. With this change, the timestamp is available alongside movement information on screen and remains available when the data is exported for review or reporting.

The added visibility helps users reconcile stock activity and provides more context when reviewing the sequence of records. It also allows teams working with exported data to refer to the same creation information shown in Stock Movements.

**Suggested validation**

- Open Stock Movements and confirm that creation timestamps appear for movement records.
- Export the movements and confirm that the `created_at` values are included and correspond to the displayed records.
- Check records with different creation dates and times, as well as any records with missing timestamps.
- Confirm that existing movement details and export functionality continue to work as expected.
