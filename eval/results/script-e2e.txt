# measured on the spoken words against scripts/bands-script.json. Rewrites: harness.py rewrite SNAP REP --set SET -j 6.
# Decision rule (written before any number): rules ship if they beat bands on scr by more than the larger rep-to-rep set-mean difference, with no more overshot, and the same holds on scr2.
# Result: neither rules nor rules-nolen beat bands on scr, so no rule was run on scr2 and references/script.md was removed after 37a1cff.
# Task 6b: every number below is on whole narrations. Until 4b6530e spoken() left blank-line runs where it removed stacked
# directions and aimeter.prose() read each run plus the next line as indented code, so assistant scripts lost 5% to 10% of
# their narration in the meter and in the judges' text (human captions lost nothing). spoken() now closes those runs, the
# script band files were recalibrated, and the same rewrites were judged again (no rewrite was redone). 'over' / 'aiside'
# use the rebuilt band file. The verdict above holds: rules and rules-nolen are not below bands.
